LensLedger can now search for the meaning of a photo while preserving its
local-first privacy model.

The new optional meaning index uses OpenCLIP to encode locally available images
and rank them from an ordinary description such as “a dog running on a beach”
or “a handwritten restaurant receipt.” Photos, search text, vectors, and results
remain on the computer. The large model runtime is not part of the standard
installation and is never installed or downloaded without an explicit opt-in.

Meaning indexing is incremental, pausable, and resumable from Library Health.
The normal catalog, tags, OCR, people, and metadata features remain fully usable
without it.

People review also gains a persistent seven-day deferral. A difficult identity
can be set aside so the queue advances to other people and does not immediately
return to the same person after LensLedger restarts.

## Included

- Optional OpenCLIP image and text encoder
- Incremental local semantic-vector storage
- Pausable background meaning-index worker
- **Meaning (optional)** search scope
- Meaning-index coverage in Library Health
- Seven-day person deferrals in the People review workspace
- Model-free deterministic CI tests for vector indexing and ranking

## Verified

- Fourteen automated database, scanner, OCR, semantic, HTTP, publishing,
  recovery, queue-management, and security tests pass.
- The base requirements do not import or install PyTorch or OpenCLIP.
- Semantic indexing and ranking are exercised in CI through an injected local
  test encoder, so CI performs no model download and uploads no image.
- The expanded Library Health panel and Meaning search scope were checked at a
  representative desktop viewport without browser warnings or errors.
