# LensLedger v0.51.0 — Camera upload auto-ingest pipeline

## Motivation

Phone camera uploads (e.g., Dropbox Camera Uploads, OneDrive Camera Roll) dump unsorted photos into a flat folder. Users want these automatically scanned, tagged, and moved into their organized collection folder. Previously, LensLedger was a passive indexer — this feature turns it into an active photo management tool.

## What changed

### Auto-ingest pipeline

A new `IngestPipeline` class (`src/ingest_pipeline.py`) runs as a background thread that periodically checks a configured source folder for new media files and moves them into the destination collection using configurable sorting rules.

### Pipeline flow

1. **Watch** — check the source folder for new media files (photos and videos matching LensLedger's supported extensions)
2. **Stability check** — wait to confirm the file isn't still being uploaded (size unchanged after a brief delay)
3. **Duplicate detection** — compute a content hash and compare against files already in the destination; skip duplicates
4. **Date extraction** — read EXIF DateTimeOriginal, falling back to file modification time
5. **Rule matching** — check filename against configurable sorting rules in order
6. **Sort** — move the file into the destination subfolder using template-based paths

### Sorting rules

Rules are defined on the Settings page. Each rule has:
- **Match pattern** — a substring matched against the filename (case-insensitive)
- **Destination** — a template path supporting `{year}`, `{month}`, `{day}`, `{hour}`, `{minute}`

If no rule matches, the default pattern `{year}/{year}_{month}_{day}` is used.

### Safety

- Files are moved, never deleted — the original is gone from the source folder only when it's safely in the destination
- Filename collisions are handled with a counter suffix (`photo_1.jpg`, `photo_2.jpg`)
- Cloud placeholders are skipped (not downloaded)
- Files starting with `.` are skipped (temp/hidden files)
- Every action (ingest, skip_duplicate, error) is logged to `ingest-log.json` with timestamps

### Configuration

Via the Settings page (Camera upload auto-ingest section):
- **Enable auto-ingest pipeline** — toggle on/off
- **Source folder** — the camera upload folder to watch
- **Destination folder** — where sorted photos go
- **Sorting rules** — add/remove rules with match patterns and destination templates

### API

- `GET /api/ingest/status` — pipeline state and stats (ingested/duplicates/errors counts)
- `GET /api/ingest/log` — last 100 ingest log entries
