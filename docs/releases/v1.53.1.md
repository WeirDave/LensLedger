# Tests no longer write to the application's data folder

## Why this release

- Running the automated test suite on a machine that also has LensLedger installed added entries to that installation's import log and application log, because the import tests did not redirect the data folder.

## What changed

### Automated tests

- The import tests now use a temporary data folder, so the import log and the application log they produce are written there and deleted with it. Previously both went to the real data folder.
- A new test confirms the import log is written to the temporary folder.
- The tests release the application log before the temporary folder is removed, as the other server tests already do.
- The running application is unchanged.

## Verified

- Full test suite: 730 tests, all passing.
- The import log in the real data folder was compared before and after a full test run and did not change.
