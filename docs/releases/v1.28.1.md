# New releases are announced within an hour

## Why this release

The automatic check for a newer LensLedger release ran at most once every six
hours, so a published release could go unannounced for most of a working day. A
check that failed was also retried on every page load for as long as the failure
lasted.

## What changed

- The automatic update check runs at most once an hour while LensLedger is in use.
  It still starts when the viewer opens, and a result younger than an hour is
  reused. A newer release is announced on the **Check for updates** entry in the
  menu, as before.
- After a failed check, for example on a network that blocks GitHub, the next
  attempt waits 30 minutes. Previously each page load tried again.
- **Check for updates** in the menu is unchanged and still checks immediately,
  whatever the interval.
- Once an update has been found, the check stops until LensLedger restarts or the
  update is installed, as before.
- The README's "Updates and rollback" section states the hourly interval.

## Not changed

- Nothing is installed automatically. An update is installed only after it is
  approved under **Check for updates**.
- The release lookup, checksum verification and install steps are unchanged.

## Verified

- Full test suite: 475 tests, all passing, including a new test file that drives
  the real check scheduler through each case: an answer under and over an hour old,
  a failure under and over 30 minutes old, a failure with no recorded time, no
  check yet, an update already found, and a manual check.
- The two interval cases fail when the old values are put back.
