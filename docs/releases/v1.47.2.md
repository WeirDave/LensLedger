# Larger version number in the page header

## Why this release

- The version number badge beside the LensLedger name at the top of each page used 10–11px text and was hard to read.

## What changed

### Every page

- The version badge in the top bar is larger: text increased to 15px, with more padding around it. The text is bold and keeps its existing colours in both the light and dark themes.
- The badge looks the same on every page. Previously its size varied slightly from page to page.

## Verified

- Full test suite: 703 tests, all passing.
- Browser check of the badge in the light and dark themes.
