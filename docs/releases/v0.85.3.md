## Film strip v2 and dark mode support

The People Index letter section dividers now use a proper 35mm film strip image (v2) instead of the earlier hand-drawn version. The new image is a realistic dark film strip with sprocket holes and transparent frames, giving the page a polished retro look.

### Image serving

The web server's static asset regex (`WEB_ASSET_NAME_RE`) was expanded to serve files from `web/img/` in addition to `web/css/` and `web/js/`. Supported image types: PNG, JPG, SVG. Content-type headers were added for each format.

### Dark mode compatibility

The film strip image has a white background, which would show as a bright rectangle in dark mode. Two CSS techniques handle this:

- **Light mode**: `mix-blend-mode: multiply` makes the white background transparent while preserving the dark film strip.
- **Dark mode**: `filter: invert(1)` flips the colors (dark strip becomes light, white bg becomes dark), then `mix-blend-mode: screen` makes the now-dark background transparent. The result is a warm golden film strip that blends naturally with the dark theme.

The dark mode rules follow the existing theme.css pattern: `[data-theme="dark"]` for explicit toggle, plus `@media(prefers-color-scheme:dark)` with `:root:not([data-theme="light"])` for system preference.

### Layout tweaks

- Reduced gap between the letter character and film strip by removing the 4px bottom margin on `.letter-char`.
- Added `margin-left: auto` to `.alpha-actions` so the action buttons (people count, Merge people, Tag faces) are pushed to the far right of the viewport.
