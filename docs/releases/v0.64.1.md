# LensLedger v0.64.1

## Better diversity sampling on Name faces page

### The problem

The Name faces page uses diversity sampling to show one representative per visual cluster, so you see a variety of different people rather than the same face over and over. Two thresholds control this:

- **Diversity threshold** (0.72): faces with similarity above this to an already-shown face are skipped in the grid
- **Suggestion threshold** (0.76): faces with similarity above this to a just-named face are auto-grouped as "Also looks like..."

The gap between 0.72 and 0.76 meant faces at 0.73–0.75 similarity slipped through the diversity filter (they were "different enough" to show) but also missed the auto-grouping (they weren't "similar enough" to batch-confirm). The result: you'd see the same person's face repeated across many cards, but naming one would only auto-match a few.

### The fix

Raised the diversity threshold from 0.72 to 0.78 — slightly above the 0.76 suggestion threshold. Now, if two faces are similar enough that naming one would eventually catch the other via "Also looks like," the diversity sampler won't show both in the first place. The grid should show genuinely different people.
