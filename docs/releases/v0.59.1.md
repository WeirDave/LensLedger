# LensLedger v0.59.1

## CI test fix for Windows short path names

The v0.59.0 release introduced a test that compared `library_db_path()` output (which resolves paths internally) against an unresolved `Path` object. On the GitHub Actions Windows runner, `tempfile.TemporaryDirectory()` returns a path containing `RUNNER~1` (a Windows 8.3 short name), while `Path.resolve()` expands it to the full `runneradmin`. The assertEqual failed because the two forms don't match.

### Fix

Added `.resolve()` to the expected-path side of the assertions in `test_library_config_is_atomic_and_databases_are_separate`, so both sides use the fully resolved path.

### Verified

- Test suite: 79 tests passed locally.
