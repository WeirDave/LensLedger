The v0.36.0 mobile responsive changes added a `.sidebar-backdrop`
overlay element for the slide-in sidebar drawer on small screens.
This element was placed inside the `.upper` CSS grid container as
a third child, but the grid only defines two columns
(`grid-template-columns: minmax(0,1fr) 430px`). The extra child
caused the sidebar to wrap below the photo on desktop viewports
instead of appearing beside it. The filmstrip also appeared
distorted because the grid layout was disrupted.

## What changed

Moved the `<div class="sidebar-backdrop">` element from inside
the `.upper` grid (between `.stage` and `.sidebar`) to outside
it (between the closing `</section>` of `.upper` and the
`<section class="filmstrip">`). The backdrop is only visible on
mobile viewports via a `position: fixed` overlay, so its position
in the DOM relative to `.upper` does not matter — it just must not
be a grid child.

## Verified

- Test suite: 79 tests, all passing.
- Browser testing (desktop 1280x800): sidebar displays on the
  right side of the photo as expected, filmstrip renders correctly
  at full width below.
- Browser testing (mobile 375x812): photo fills the viewport width,
  filmstrip at bottom, sidebar toggle button visible.
