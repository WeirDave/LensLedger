# Python packages are kept up to date, and PyTorch's companion package matches

## Why this release

- The launcher installed LensLedger's Python packages only when one was missing or older than the minimum in requirements.txt. pip itself and the optional feature packages were never updated, so an installation slowly fell behind.
- Switching meaning search to an NVIDIA graphics card replaced PyTorch but left torchvision at the version built for the previous PyTorch. The pair kept working, but pip reported them as incompatible.

## What changed

### Weekly package update

- About once a week, **Start LensLedger.cmd** now updates pip, the packages LensLedger always needs (Pillow and pillow-heif), and every optional feature package that is installed (meaning search and face detection), each within the version range requirements.txt allows. The launcher window lists each step.
- The first launch on a computer starts the weekly clock without updating anything, because the packages were just installed. A later launch more than a week after the last successful update runs it.
- The update waits for a launch when LensLedger is not already running, because a running LensLedger holds PyTorch's files open. A failed update, such as when the computer is offline, is retried the next day. A failed update never stops LensLedger from starting.
- PyTorch is updated from the download site its installed build came from. An NVIDIA build is updated from PyTorch's NVIDIA download site together with torchvision, and a processor build together with torchvision from the standard site. The graphics-card face-detection runtime (onnxruntime-gpu) is updated as itself, so neither is replaced by the slower processor version.
- Python itself is not updated.

### Settings

- **Settings > Startup** has a new switch, **Keep pip and LensLedger's Python packages up to date**. It is on by default; switching it off stops the weekly update.

### Graphics-card setup

- Installing the NVIDIA build of PyTorch, from setup or from **Use my graphics card**, now installs the matching torchvision from the same download site.
- The card-detection code moved into a small module of its own that the launcher can use before LensLedger's other packages are present. Behaviour is unchanged.

### Manual

- The manual describes the **Startup** settings and the weekly update.

## Verified

- Full test suite: all passing. New tests cover reading the optional packages from requirements.txt, the update plan for each combination of installed packages (including an NVIDIA PyTorch and the graphics-card face runtime), when an update is due, retrying a failure after a day, skipping while LensLedger is running, honouring the switch in Settings, and the matching torchvision.
