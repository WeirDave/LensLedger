When reviewing faces in the enlarged photo lightbox, there was no way to see which photo you were looking at or navigate to it on disk. The face cards below showed a truncated path and tooltip, but once the lightbox opened, that context was gone.

## What changed

The enlarged photo lightbox now includes a path bar at the bottom showing the photo's folder and filename. A "Show in folder" button next to it opens the file's location in Explorer (Windows) or Finder (macOS), using the existing `reveal-file` API.

The path text uses right-to-left direction for truncation, so when the path is too long, the folder prefix gets ellipsized while the filename stays visible — the same approach used in the face card captions.

## Verified

- Test suite: 88 tests, all passing.
- Browser verification: opened the People review page on a real library, clicked Enlarge on a face card, confirmed the path and "Show in folder" button appear at the bottom of the lightbox.
