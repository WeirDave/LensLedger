# LensLedger v0.45.5 — Larger, cleaner photo navigation arrows

## Motivation

The previous/next photo navigation buttons on the viewer stage used text
characters (`‹` and `›` — single angle quotation marks) at 25px inside 42px
circular buttons. These rendered too small, didn't fill the circles, and
looked amateurish compared to the rest of the UI.

## What changed

- Replaced the `‹` / `›` text characters with inline SVG chevron arrows
  (stroke-based, 20x20 viewBox, 2.5px stroke width). The SVGs inherit
  `currentColor` so they respect the existing theme.
- Increased button size from 42px to 48px circles.
- Added `display:grid; place-items:center` to `.stage-nav` for reliable
  centering of the SVG icons (replacing the old font-size approach).
- Removed the now-unnecessary `font-size:25px` from the nav button CSS.

## Verified

- Test suite: 79 tests passed.
- Visual verification: confirmed in browser that the chevron arrows render
  centered inside the circular buttons and are clearly visible at the new size.
