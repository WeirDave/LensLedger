## Why this release

Photos tagged by other software often store their keywords in the IPTC
Keywords field or Microsoft's keyword list rather than the XMP subject list,
and may name the people in them in the IPTC "people in image" field. LensLedger
only read the XMP subject list, and only from JPEG files.

"Write all tags" replaces a photo's keyword and people fields with what
LensLedger holds. Anything the scan had not read was therefore removed from the
photo: IPTC-only keywords, every tag in a HEIC file, and any name in the people
field that was not a confirmed person in LensLedger.

## What changed

- Scanning reads keywords from XMP subject, IPTC Keywords and Microsoft's
  keyword list, merged into one list with duplicates removed regardless of
  capitalisation. It also reads the "people in image" names. Both apply to
  JPEG and HEIC files.
- IPTC keywords written without a character-set marker are read as Latin-1,
  the usual convention for older software.
- "Write all tags" writes confirmed people first, followed by any other names
  the photo already carried. Names hidden from a photo in LensLedger are still
  left out.
- Names from a photo's people field are searchable in the Image search scope.
- Renaming a person also hides the old name when it came from the photo's
  people field, as it already did for keywords.
- The next scan after updating re-reads the tags of photos already in the
  index, once, without changing the photos. On a large library this adds
  some time to that scan.

## Fixed during testing

- "Write all tags" doubled every keyword and name that was already in the
  photo. The write cleared each field and then appended to it in the same
  ExifTool command, and ExifTool keeps the old values in that case. Each field
  is now replaced as a whole list. Photos that were already affected are
  cleaned up the next time "Write all tags" writes them, because the
  duplicates are merged when the photo is read.

## Verified

- Full test suite: 210 tests, all passing, on Python 3.12.10 (up from 203).
- New tests build synthetic JPEG and HEIC files carrying each field and check
  that the scan reads them, that duplicates are merged, and that photos
  already in the index are re-read once and left unchanged.
- An end-to-end test with the bundled ExifTool writes IPTC-only keywords,
  a Microsoft keyword and an unconfirmed name into a photo, runs
  "Write all tags", and checks that everything is kept without duplicates.
