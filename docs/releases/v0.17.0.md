LensLedger now guides a new user from an empty install to a useful, private
photo inventory.

The welcome screen suggests likely Windows photo folders, explains what the
local scan does, and shows live discovered, indexed, unchanged, cloud-only, and
error counts. A scan can be paused safely and resumed later. When it completes,
LensLedger presents a concise report of images, videos, RAW originals,
metadata-ready files, and cloud placeholders before opening the library.

Library management now remembers every library a user has opened and provides
the same progress and pause controls when adding or switching libraries. Common
camera RAW formats are classified separately and shown with a clear placeholder
until browser previews are supported. WAV audio is no longer misclassified as a
photo-library asset.

The Windows launcher now checks for Python and installs LensLedger's required
packages automatically on first launch.

## Included

- Guided empty-database onboarding
- Suggested and remembered photo-library locations
- Live scan progress plus safe pause and resume
- First-scan inventory report
- Incremental rescanning and removal tracking
- RAW photo inventory and explicit viewer state
- New-user dependency setup in the Windows launcher
- Database schema version 2 with cancelled-run history

## Verified

- A fresh database starts empty at schema version 2.
- A first scan indexes new files; a second scan skips unchanged files.
- A cancelled scan preserves unseen records, and its resumed scan removes files
  that are genuinely missing.
- RAW originals are inventoried while WAV audio is ignored.
- Database backups pass SQLite integrity and foreign-key checks.
- The first-run, completion-report, standard viewer, and RAW states were checked
  in the in-app browser without console warnings or errors.
- All Python application and test sources compile successfully on Python 3.11
  grammar.
