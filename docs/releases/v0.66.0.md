# LensLedger v0.66.0 — Unidentified face counts and Name Faces routing

## Motivation

After finishing People Review, users were sent back to the home page with no indication of how many faces still needed naming. The workflow should guide users back to Name Faces when unidentified faces remain, since naming more faces generates new suggestions for the next round of People Review.

## What changed

### Review queue API

The `/api/people/review/queue` response now includes `unidentified_faces` — the count of detected faces with no confirmed name (same query the Name Faces page uses).

### Header progress

The Review People header now shows the unidentified face count alongside the existing counts:

```
423 photos · 13 people remaining · 1,247 unnamed faces
```

### Done state routing

When People Review finishes but unidentified faces remain, the completion screen shows:

- The count of remaining faces
- A message explaining that naming more faces generates new suggestions
- A large "Name faces (N)" button linking to `/faces-review`

When all faces are identified, the original "Return to the photo library" link is shown.

## Files changed

- `src/photo_search.py` — added `unidentified_faces` count query to `people_review_queue()`
- `web/js/people-review.js` — added `showDoneState()` helper, updated progress text to include unnamed face count
