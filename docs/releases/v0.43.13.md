# LensLedger v0.43.13 — Clean restart experience

## Context

The console startup had accumulated redundant messages ("Starting
LensLedger..." from the .cmd, "Loading LensLedger..." from Python, then
the full banner). More importantly, on restart the server opened a new
browser tab even though the existing tab auto-reloads to the new version
(the stale-version banner's JavaScript polls and reloads once the server
comes back).

## What changed

1. Removed the "Starting LensLedger..." echo from `Start LensLedger.cmd`.
   The console now shows just the normal banner once the server is ready.

2. On restart (`--restarted` flag), the banner line reads
   "LensLedger v0.43.13 — new version loaded." instead of the plain
   version string.

3. On restart, `webbrowser.open` is skipped — the existing browser tab
   already auto-reloads via the stale-version poller.
