UI polish, consistent theming, and permanent delete for trashed photos.

## What changed

### Compact sidebar

Reduced padding, font sizes, and gaps throughout the sidebar to minimize
scrolling. Chips went from 6px/8px padding to 3px/6px, section spacing
from 14px to 8px, and action buttons (Save subject, Add tags, etc.) are
now 12px font with tighter padding. Info buttons (ⓘ) are excluded from
the compacting and retain their original circular styling.

### Consistent theme toggle

The theme toggle button was inconsistent across pages — different sizes
(30px vs 34px), different backgrounds (`--surface3` vs `--btn-secondary`),
and missing `border-radius: 50%` on the viewer. Moved the shared
`.theme-toggle` rule into `theme.css` so all six pages use the same
32px round button with `--btn-secondary` background. Removed per-page
overrides from viewer.css, map.css, scan-photos.css, people-review.css,
faces-review.css, and onboarding.css.

On the viewer page, the theme toggle was also relocated from the left
side of the header (before the logo) to the right side (after the
summary), matching the placement pattern on all other pages.

### Trash button in toolbar

The "Move to Trash" button moved from the top header bar into the
search toolbar form, placed immediately after the "View" button. This
keeps destructive actions grouped with the toolbar controls and frees
space in the header. Label shortened from "🗑 Move to Trash" to
"🗑 Trash" for toolbar fit.

### Permanent delete

The Trash & Restore panel now has a "Delete" button on each trashed
item. Clicking it prompts for confirmation, then permanently deletes
the file from the review bin and removes the asset and all associated
data (tags, people, faces) from the database. This is irreversible.

### Enriched About panel

The About LensLedger modal now includes links to the developer's other
public projects: WaxFrame Professional, WaxFrame Free, Subscription
Wizard, and WD Wireless Tools.

### Cache-busting for logo and favicon

All logo (`/logo.png`) and favicon (`/favicon.png`) references now
include `?v={APP_VERSION}` query parameters, matching the pattern
already used for CSS and JS assets. This prevents browsers from
showing stale images after a logo change.

### Tooltip text fix

The metadata editor tooltip previously said "until you click Preview &
publish" — updated to "until you use Publish to this photo" to match
the actual section heading.

## Verified

- Visually verified sidebar compacting, theme toggle consistency, trash
