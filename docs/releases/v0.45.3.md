## Motivation

v0.45.0 added automatic learning when the review queue empties on both the
Name Faces and People Review pages.  The "Find more matches" button was left
in the header as a manual fallback, but its purpose was unclear — users
didn't know what it did or when to click it, and the automatic behavior
already covered the same functionality.

## What changed

- Removed the "Find more matches" button from the Name Faces page header.
- Removed the "Find more matches" button from the People Review page header.
- Removed the associated `runLearning` / `findMatches` click handlers from
  both JavaScript files.
- Updated the Name Faces intro paragraph to explain the automatic workflow
  ("teaches LensLedger to find the rest automatically") instead of
  referencing the removed button.

The automatic learning behavior from v0.45.0 is unchanged — it still
triggers when the queue empties on either page.

## Verified

- Test suite: 79 tests, all passing.
- Name Faces page loads without the button and without console errors.
- Intro text updated correctly.
