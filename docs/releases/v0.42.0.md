## Motivation

LensLedger bakes `APP_VERSION` into CSS/JS cache-bust parameters at import
time. When source files are updated on disk while the server is still running,
the browser continues serving stale assets with the old version query string.
Users had no indication that a restart was needed to pick up changes.

The WD-Wireless-Tools project solved this with a stale-server detection
pattern — a `/api/version` endpoint that compares the running version against
the on-disk version, and a client-side poller that shows a warning banner when
they diverge. This release ports that pattern to LensLedger.

## What changed

### Stale-server detection

- Added module-level `_STARTUP_VERSION` and `_STARTED_AT` variables that
  freeze the version and UTC timestamp when the server process starts.
- Added `/api/version` GET endpoint returning `version`, `startedAt`,
  `onDiskVersion`, `restartReady`, and `pid`.
- Added client-side `checkServerVersion()` in `viewer.js` that polls
  `/api/version` every 30 seconds. When `restartReady` is true, it injects a
  warning banner at the top of the page with:
  - A warning icon and message showing the old and new versions.
  - A "Restart server" button that POSTs to `/api/update/restart-source`,
    then polls `/api/version` until `startedAt` changes, and reloads the page.
  - A close button to dismiss the banner.
- Added `.stale-banner` CSS styles in `viewer.css` with a warm amber theme
  that fits both light and dark modes.

### Localhost URL

- Changed the server bind address and startup URL from `127.0.0.1` to
  `localhost` for consistency with the browser preview configuration.

## Fixed during testing

The initial implementation named the API handler method `server_version()`,
which shadows `BaseHTTPRequestHandler.server_version` — a class attribute
(string) that Python's `version_string()` concatenates with `sys_version`.
The shadow caused `TypeError: unsupported operand type(s) for +: 'method'
and 'str'` in 36 tests. Fixed by renaming the method to `version_info()`.

## Verified

- Test suite: 79 tests passed.
- Browser verification: confirmed `/api/version` returns correct JSON with
  `restartReady: false` when versions match, and no stale banner appears.
- Info buttons remain correctly styled at 16px with `currentColor` borders.
