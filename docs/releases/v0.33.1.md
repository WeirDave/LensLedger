The "Start Scan All" button had no visual feedback while the request was
in flight. Clicking it disabled the button (preventing double-clicks) but
the label stayed "Start Scan All," so it wasn't obvious anything was
happening — especially on a slower connection or a large library where the
server takes a moment to respond.

Now the button text changes to "Starting scan..." immediately on click,
and resets to "Start Scan All" if the request fails.

Also ships the `CLAUDE.md` and `CONVENTIONS.md` files that standardize
the release ceremony, commit format, and coding conventions for all AI
assistants (Claude Code, Aider, etc.) working in this repo.
