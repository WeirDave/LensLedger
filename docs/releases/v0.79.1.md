## Motivation

The v0.79.0 release added `load_all_known_libraries()` which compared library paths to determine which one was the "current" library. The comparison used `Path.resolve()` on the library entries but compared against the raw `current_root` string from the state file. On CI runners, `Path.resolve()` can normalize paths differently (e.g., drive letter casing, symlink resolution), causing the `is_current` flag to be `False` when it should be `True`.

## What changed

Both the `current_root` value and each library entry are now resolved through `Path.resolve()` before comparison, ensuring consistent normalization regardless of how the path was originally written.
