## What changed

**A stray backslash in the manual page.** Version 1.7.0 added a line to the
manual describing where the log file lives. The folder name was written with a
single backslash, which Python reads as the start of an escape sequence. It
does not recognise this one, so it warns and carries on — today. On a future
version of Python that warning becomes a hard error, and LensLedger would not
start at all.

The warning scrolled past unnoticed because the program still ran. A new test
now compiles every source file and fails on any warning of this kind, so the
next one cannot reach a release. Reintroducing this exact fault was confirmed
to fail it.

**Creating a database backup now says so.** It recorded that it had been asked
for, but not where the backup went or how big it was.

## Verified

- Full test suite: 192 tests, all passing, on Python 3.12.10 — up from 190.
