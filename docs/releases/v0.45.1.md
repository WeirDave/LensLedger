# LensLedger v0.45.1

## Trash button and face label styling

The trash button on review cards was a plain text button that didn't read as destructive. It now has a red danger background with a crisp inline SVG trash can icon and white text, clearly signaling "this deletes something" in both light and dark modes.

The "Face being checked" label on people review cards used a muted olive-yellow (`#a88018`) in light mode that blended into light backgrounds. It now uses the same bright golden yellow (`#d4a840`) as dark mode, making face boxes pop consistently regardless of theme.

- Test suite: 79 tests passed.
- User confirmed visual appearance in both light and dark mode.
