# LensLedger v0.43.6 — Move Trash button to sidebar

## Motivation

The "Trash" button in the top toolbar was ambiguous — it could be read as navigating to the trash view rather than trashing the currently selected photo. Users might hesitate to click it or confuse it with the "Trash & restore" menu item.

## What changed

- Removed the `🗑 Trash` button from the top toolbar.
- Added a `🗑 Trash this photo` button to the sidebar card, placed after the "Publish to this photo" section and before "Information already in this photo."
- The button label now clearly communicates the action: it trashes the selected photo, not navigates somewhere.
- The button is automatically disabled when no photo is selected (covered by the existing sidebar control disabling logic).

## Verified

- Test suite: 79 tests passed.
- Visual placement confirmed via read_page — button appears in the sidebar with the correct label and styling.
