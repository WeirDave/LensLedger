## Motivation

The navigation menu was different on every page — the home page had the most complete version with Tools and Help sections, the Review people and Name faces pages had a partial menu missing the current page's link, and the Scan photos and Photo map pages had no hamburger menu at all (just a small quick-nav link bar that disappeared on narrow screens). This made the app feel inconsistent and made it harder for users to navigate.

## What changed

- Created a single `nav_menu()` Python function that generates the identical menu HTML, used by all five pages. The menu is now truly static — same items, same order, same sections, on every page.
- Menu order reflects the intended user workflow: Home, Scan photos, Name faces, Review people, Photo map.
- Replaced the quick-nav link bars on the Scan photos and Photo map pages with the full hamburger menu panel, including all the same CSS and JS as the other pages.
- Added Quick guide and Check for updates buttons to sub-page menus — clicking them redirects to the home page where those panels are implemented.
- Enlarged the menu logo from 32px to 40px across all five CSS files.

## Verified

- **Test suite:** 79 tests passed (Python, Windows).
- **Browser verification:** Opened the hamburger menu on all five pages (Home, Scan photos, Name faces, Review people, Photo map) and confirmed the menu contents are identical on each. Verified the larger logo renders correctly.
