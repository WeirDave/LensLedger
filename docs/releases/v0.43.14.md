# LensLedger v0.43.14 — HEIC lightbox preview fix

## Context

Double-clicking a face card on the Name faces page is supposed to open a
lightbox showing the full photo for context. This stopped working for
HEIC/HEIF images — the lightbox opened but showed a blank image.

The root cause: the `/media` endpoint served raw HEIC files with
`Content-Type: image/heic`. Browsers cannot render HEIC natively in an
`<img>` tag, so the image loaded with zero dimensions. Face thumbnails
were unaffected because the `/media-face` endpoint already converts crops
to JPEG via Pillow.

## What changed

The `/media` endpoint in `src/photo_search.py` now detects `.heic` and
`.heif` files and converts them to JPEG (quality 90) using Pillow before
serving. EXIF orientation is applied during conversion. All other image
formats continue to be served as raw files, unchanged.

This fixes the lightbox on every page that uses `/media?id=`: Name faces,
Review people, Photo map, and the asset detail viewer.

## Verified

- Test suite: 79 tests passed.
- Browser verification: confirmed the lightbox now renders a HEIC photo
  (4032x3024 natural dimensions, served as `image/jpeg`) after the fix,
  where it previously showed `naturalWidth: 0` with `image/heic`.
