# LensLedger v0.43.7 — Loading message before imports, browser tab reminder

## Context

v0.42.2 and v0.43.3 added echo lines to `Start LensLedger.cmd` to fill
the blank console window during startup. However, the console was still
appearing blank — the echo might print but the real delay is Python
loading heavy dependencies (PIL, torch, CLIP, face detection) which takes
several seconds with no further output.

Additionally, when LensLedger restarts after a version update, the old
browser tab is left behind with no indication that it should be closed.

## What changed

Added an immediate `print()` at the very top of `photo_search.py`, before
any `import` statements, guarded by `if __name__ == "__main__"`:

```
  Loading LensLedger...
  (If you still have a previous browser tab open, you can close it.)
```

This prints the instant Python starts executing the file — before PIL,
torch, CLIP, face detection, or any other heavy module is loaded. The
`flush=True` ensures it appears immediately and isn't buffered.

The `if __name__ == "__main__"` guard ensures the message only appears when
running the server directly, not when the module is imported by tests or
other tools.

## Verified

- **Test suite:** 79 tests, all passing.
- **Import guard:** confirmed `import photo_search` does NOT print the
  startup message.
