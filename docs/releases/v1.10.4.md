## Why this release

LensLedger's Python packages were spread over three files:
`requirements.txt` for the base install, `requirements-semantic.txt` for
meaning search and `requirements-face.txt` for face-location recovery. They
are now one file.

## What changed

- `requirements.txt` holds every package. The base packages (Pillow and
  pillow-heif) are ordinary lines and are the only ones installed on first
  launch.
- The optional packages are listed below them, commented out, under
  `# [meaning-search]` and `# [face-locations]`. Meaning search alone is a
  download of several gigabytes, which is why it stays out of the first-launch
  install.
- The button in Settings that installs meaning search, and the one that
  installs face detection, now install the packages from their section of
  `requirements.txt`.
- The README gives the `pip install` commands for installing either optional
  feature by hand.
- Release ZIPs still contain `requirements-semantic.txt` and
  `requirements-face.txt` as one-line placeholders. Copies of LensLedger up to
  v1.10.3 check a downloaded update for those two files and would otherwise
  refuse to install it. After updating, LensLedger reads only
  `requirements.txt`.

## Verified

- Full test suite: 222 tests, all passing, on Python 3.12.10. New tests check
  that the first-launch install lists only Pillow and pillow-heif, that each
  optional section yields its packages, and that an unknown section is an
  error rather than an empty install.
- `pip install --dry-run -r requirements.txt` resolves only the base
  packages.
