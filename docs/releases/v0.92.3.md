## Motivation

The group manager page truncates long names with ellipsis (`text-overflow: ellipsis`) to keep the card layout clean, but there was no way to see the full name without guessing. Names like "Amanda Kramer, The Psychedlic Furs, The Furs" or "Kristen Kimberly Hart Benton aka Mallory Black" were cut off with no hover tooltip.

## What changed

Added `title` attributes to person name elements on the cards and group name elements in the sidebar. When a name is truncated, hovering reveals the full text in a native browser tooltip.

## Verified

- Test suite: 88 tests passed.
- DOM verification: confirmed that truncated names (scrollWidth > clientWidth) all have matching `title` attributes with the full text.
