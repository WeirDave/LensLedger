Clicking a photo marker on the Photo Map page used to navigate away to the main viewer, leaving no easy way to return to the map and continue browsing nearby locations.

## What changed

Markers now open a full-screen lightbox overlay instead of navigating away. The lightbox shows the photo with its filename, date range, and coordinates, plus three action buttons:

- **Open in viewer** — jump to the photo in the main viewer (the old behavior, now opt-in)
- **View all photos here** — browse all photos near that location
- **OpenStreetMap** — see the exact coordinates on OpenStreetMap

When a marker represents a cluster of photos at the same coordinates, prev/next arrows let you step through all photos in the cluster. A counter (e.g. "3 / 7") shows your position.

The lightbox closes with:
- The × button in the top-right corner
- Pressing Escape
- Clicking the dark backdrop outside the photo
- Keyboard left/right arrows navigate between photos in a cluster

The overlay works identically on both the 3D globe view and the street-level Leaflet map view, and uses fixed dark styling that looks correct in both light and dark themes.

## Implementation

- Added lightbox HTML to the map page template in `src/photo_search.py`
- Added lightbox CSS to `web/css/map.css` with responsive breakpoints for mobile
- Replaced the old `show()` function in `web/js/map.js` with `showLightbox()` / `renderLightboxPhoto()` / `closeLightbox()` functions that manage the overlay state
- The `show()` function still exists as the public entry point but now delegates to `showLightbox()`
