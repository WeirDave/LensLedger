# LensLedger v0.62.0

## Console window activity logging

The terminal window where LensLedger runs was blank after the startup banner. It now shows timestamped log lines for every significant operation:

```
  [14:32:05] Library: C:\Dropbox\Photos
  [14:32:05] Database: C:\Dropbox\Photos\.LensLedger\LensLedger-Photos.sqlite3
  [14:32:05] Folder watcher: enabled (every 30 min)
  [14:32:10] Scan started: C:\Dropbox\Photos
  [14:33:45] Scan complete — 12 changed, 0 removed, 50,264 total assets
  [14:33:45] OCR started
  [14:34:20] OCR complete — 12 images processed
  [14:34:20] Meaning search indexing started
  [14:35:01] Meaning search complete — 12 images indexed
  [15:02:05] Folder watcher: checking for changes
  [15:02:10] Scan started: C:\Dropbox\Photos
  [15:02:15] Scan complete — 0 changed, 0 removed, 50,264 total assets
```

### What gets logged

- **Startup:** current library path, database path, and which background services are active
- **Scans:** started, completed (with counts of changed/removed/total), paused, or failed
- **OCR:** started, completed (with image count), paused, or failed
- **Meaning search:** started, completed (with index count), paused, or failed
- **Face detection:** started, completed (with face/photo counts), paused, or failed
- **Folder watcher:** each periodic check
- **Auto-import:** each periodic check, and results when files are processed

### Implementation

A new `console_log` module provides a single `log()` function that prints `[HH:MM:SS] message` to stdout. All modules that run background work import it.
