The v0.39.0 light theme had three layout and visual problems on
desktop: a blank space between the photo and filmstrip, compressed
filmstrip thumbnails, and a washed-out light palette with
insufficient contrast between surfaces.

## What changed

### Fixed blank space and filmstrip layout

The `.sidebar-backdrop` div (used only on mobile to dim behind the
slide-in sidebar) sits between `.upper` and `.filmstrip` inside the
`.viewer` grid. On desktop it had no CSS rule at all, so it
defaulted to `display:block` and claimed the 158px grid row meant
for the filmstrip. The filmstrip was pushed into an implicit
auto-sized third row and clipped by `overflow:hidden`.

Fix: added `.sidebar-backdrop{display:none}` to the base (non-media-
query) rules in `viewer.css`. The mobile `@media(max-width:768px)`
block already sets `display:none` and toggles to `display:block` via
the `.open` class, so mobile behavior is unchanged.

### Redesigned light palette

The original light theme used pure white (`#ffffff`) for nearly
every surface — header, sidebar, inputs, menus — creating a flat,
washed-out appearance with no visual hierarchy.

The revised palette uses:

- **Dark photo stage** (`--bg-deep: #3a3832`) — warm charcoal that
  frames photos the same way the dark theme does, instead of light
  gray that competes with the image
- **Warm off-white surfaces** (`--surface: #faf9f7`) — sidebar,
  header, menus, and modals use a subtle warm tint instead of
  clinical white
- **Warm beige background** (`--bg: #ece9e4`) — the page ground has
  visible warmth, distinguishing it from the lighter surfaces on top
- **Distinct filmstrip** (`--filmstrip-bg: #d8d4cc`) — clearly
  separated from both the stage above and the sidebar beside it
- **Warmer borders** (`--border: #d0c9bf`) — borders and input
  outlines carry the warm tone instead of cool blue-gray
- **Stronger shadows** — shadow opacity increased from near-invisible
  (`#0001`) to subtle-but-present (`#00000014`)

The dark theme is completely unchanged.

## Verified

- Test suite: 79 tests, all passing.
- Layout verification: `gridTemplateRows` is `442px 158px` (two
  explicit rows, no implicit third). `.sidebar-backdrop` computes
  `display:none` on desktop. Filmstrip thumbnails render at full
  `170×132` size.
- Light theme: stage background is dark (#3a3832), header/sidebar
  are warm off-white (#faf9f7), filmstrip is warm medium (#d8d4cc),
  page background is warm beige (#ece9e4).
- Dark theme: all values unchanged from v0.39.0.
- No console errors.
