# LensLedger v0.57.0

## Browse dialog, library management, and database location

Several issues made it difficult to manage multiple libraries, especially when photos lived on external drives.

### Browse dialog fix

The folder browse dialog (used when adding a library or selecting folders) was opening behind the browser window, making it appear as if the button did nothing. The dialog now opens as a topmost window so it always appears in front.

### Add library without scanning

Previously, adding a library from the Settings page immediately switched to it and started a full scan. If another scan was already running, the operation was rejected entirely. Now, adding a library registers it in the library list without starting a scan, so users can set up multiple libraries and scan them at their convenience.

### Database location choice

The database was always stored in the application data folder (`%LOCALAPPDATA%\LensLedger\Libraries\`). Users can now choose to store it inside the photo library folder instead. This is especially useful when photos live on an external or shared drive — keeping the database with the photos means the index travels with the drive.

The option appears both on the initial setup page and when adding a new library from Settings.

### Relocate library

There was no way to move a library from one location to another after the initial scan. For example, if you started scanning photos on a USB drive and then copied them to your hard drive, you had to start over. The new "Relocate" button on the Settings page lets you point an existing library at a new folder location. It updates all file paths in the database so the existing index, tags, and scan results carry over.
