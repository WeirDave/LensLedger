# One Add tags box and plain explanations in the side panel

## Why this release

- The viewer's side panel had two separate boxes for adding tags, one for the photo and one for its folder, and seven small "i" buttons that hid a sentence of explanation each. The two boxes looked alike and the explanations were easy to miss.

## What changed

### Photo viewer side panel

- **Add tags** (under **Photo tags**) is the one box for adding tags. The **Add to** menu below it has two choices:
  - **This photo** (default): the tags are added to the selected photo, as before.
  - **Every photo in this folder**: the tags are added to every photo in the selected photo's folder, as **Add to event** did before.
- After an add, the menu returns to **This photo**, so adding to a whole folder needs a deliberate choice each time.
- The separate box and **Add to event** button under **Event / folder tags** are removed. That section still lists the folder tags, and each one can still be removed from the photo with its ×.
- The "i" buttons beside **Metadata for this photo**, **Primary subject**, **Photo tags**, **People in this photo**, **Event / folder tags**, **Publish to this photo** and **Hidden tags** are removed. Each explanation is now a short visible line under its heading, worded in plain language. Collapsing a section hides its line with it.
- The "i" button next to **Search scope** in the toolbar is unchanged.

### Phone width

- The **Add to** menu is 44px tall on a phone, like the other fields.

### Manual

- The manual's **Photo tags** and **Event / folder tags** entries describe the **Add tags** box and the **Add to** menu.

## Verified

- Test suite: all passing, with new tests for the single field, the folder choice returning to **This photo**, and the side panel having no "i" buttons.
- Browser, on a test library: both add routes work, the folder route shows "2 folder tags added to 3 photos", the menu returns to **This photo**, and the panel looks right in the dark and light themes and in a 390px-wide window with the Details drawer open.
