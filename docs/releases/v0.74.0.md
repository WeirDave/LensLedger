# LensLedger v0.74.0 — Recognition confidence and confirm-all-remaining

## Motivation

After the batch size increase to 200 and auto-confirm at 0.75, naming a person
with thousands of photos still required clicking "Confirm all" dozens of times —
each round showing 200 borderline matches (0.65–0.75 similarity), waiting for
the next batch, and clicking again. With 3,000+ confirmed faces the centroid is
rock solid, and every borderline match is almost certainly correct.

Users wanted two things:
1. A way to see how confident the system is about knowing a face.
2. A way to skip the repetitive click-through and confirm everything at once.

## What changed

### Recognition confidence percentage

`find_more_faces` now calculates cohesion — the median similarity of all
confirmed face vectors to their centroid — and returns it as a percentage.
The match group header shows this alongside the auto-confirmed count:

> Also looks like R. David Paine III  ·  24 auto-confirmed  ·  87% confidence

This gives the user a clear signal of how well the system knows this face.

### "Confirm all remaining" button

When a person has at least 25 confirmed faces and 75%+ confidence, a
"Confirm all remaining (N)" button appears in the match group header. One click:

1. Confirms the currently displayed borderline matches via batch endpoint
2. Calls the new `/api/faces/confirm-remaining` endpoint
3. The server loops internally: compute centroid → find all matches ≥0.65 →
   confirm → recompute centroid → repeat until no new matches
4. Returns the total confirmed count

This turns a 15+ click process into a single click. The server logs each round:

```
[Name faces] Confirm-all round 1: 1847 confirmed for "R. David Paine III" (1847 total)
[Name faces] Confirm-all round 2: 312 confirmed for "R. David Paine III" (2159 total)
[Name faces] Confirm-all complete: 2159 confirmed for "R. David Paine III" in 2 round(s)
```

### Threshold logic

The button only appears when:
- **25+ confirmed faces**: the centroid is stable enough to trust
- **75%+ confidence**: cohesion is high enough that borderline matches are reliable

Below these thresholds, the normal review-200-at-a-time flow continues.
