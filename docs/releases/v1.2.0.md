## Motivation

The "Set up face detection" button on the Scan Photos page always appeared as an install button, even when face detection was already installed. Clicking it would re-run the install process or show an error. This was inconsistent with how meaning search handled its setup — meaning search already had a dedicated section in Settings showing model status, download size, and file path, while the Scan Photos page just linked to it.

## What changed

Face detection setup now follows the same pattern as meaning search:

### Settings page

A new **Face detection model** section appears in Settings (between "Meaning search model" and "Display preferences"). It shows:

- **When not installed:** An install button with a description of the download size (~500 MB), matching the meaning search install flow with progress polling and error handling.
- **When installed:** The buffalo_l model name, a "Downloaded" badge with its size on disk, a description, and the model's file path on the local filesystem.

The section is also linked in the Settings sidebar table of contents.

### Scan Photos page

The inline "Set up face detection" button has been replaced with a "Set up face detection in Settings" link that navigates to `/settings#face-detection`, matching how the meaning search section already uses a "Set up meaning search in Settings" link.

### Backend

- Added `model_cache_info()` to `face_locations.py` — scans the InsightFace model directory (`~/.insightface/models/buffalo_l/`) for `.onnx` files and reports download status, total size, and path.
- The `/api/faces/status` endpoint now includes `model_cache` in its response when face detection is installed.

## Verified

- Test suite: 113 tests passed.
- Browser verification: confirmed the Settings page shows the face detection section with "Downloaded · 326 MB" and the correct model path when installed. Confirmed the Scan Photos page shows a settings link instead of an install button. Confirmed the install actions are hidden and scan actions are shown when face detection is installed.
