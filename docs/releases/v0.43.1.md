# LensLedger v0.43.1 — HEIC face detection fix

## Motivation

v0.43.0 added `pillow-heif` and registered it in the four Pillow-based
modules, but the face scanner (`face_scan.py`) and face location recovery
(`face_locations.py`) use OpenCV's `cv2.imdecode()` instead of Pillow.
OpenCV cannot decode HEIC, so `imdecode` returns `None` and those 22 HEIC
photos still failed face detection with "image could not be decoded."

## What changed

In both `face_scan.py` and `face_locations.py`, when `cv2.imdecode` returns
`None`, the code now falls back to Pillow:

1. Opens the file with `Image.open()` (which uses `pillow-heif` for HEIC).
2. Converts to RGB.
3. Wraps in a numpy array and converts RGB to BGR for OpenCV/InsightFace.

The fallback is lazy-imported inside the `if image is None` branch, so it
adds zero overhead for formats OpenCV handles natively.

## Verified

- Test suite: 79 tests passed.
- Confirmed `cv2.imdecode` returns `None` for a real HEIC file, and the
  Pillow fallback produces a valid `(H, W, 3)` uint8 BGR array that
  InsightFace can process.
