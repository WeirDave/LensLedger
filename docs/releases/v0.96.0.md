The Photo Map page now supports a seamless multi-level zoom experience, from a high-altitude globe view all the way down to street-level detail.

## Motivation

The 3D globe introduced in v0.95.0 was great for seeing where photos were taken around the world, but there was no way to drill down to street-level detail. At close zoom, globe markers would pile up and the spherical projection made it hard to distinguish nearby locations. Users needed a way to go from "somewhere in Florida" to "this exact intersection" without leaving the page.

## What changed

### Progressive globe zoom

Clicking a cluster marker on the globe now zooms in at 0.75x per click instead of the previous aggressive 0.4x. This gives a cleaner 3–4 step progression:

1. **World view** — one marker per region
2. **Continental view** — markers spread across countries
3. **Regional view** — individual cities become visible
4. **Close zoom** — city-level clusters, ready for street view

The clustering cell size now scales linearly with camera distance (`camDist * 25`), producing a natural "reveal more as you zoom" effect.

### Globe-to-street-map transition

When a cluster click would bring the camera distance below 1.7 (the transition threshold), the globe hides and a Leaflet-powered OpenStreetMap view appears at the same geographic location, zoomed to level 13. The transition happens instantly — no loading screen, no page navigation.

### Street-level markers

Photo locations appear as styled markers on the street map, using the same visual language as the globe markers (single dots for individual photos, numbered circles for clusters). Clicking a cluster zooms in further; clicking a single marker opens the photo details panel with preview, date, coordinates, and action links.

Street markers re-cluster dynamically as the user pans and zooms the map, with tighter clustering at lower zoom levels and looser clustering at high zoom.

### Returning to the globe

Three ways to get back:

- **Home button (⌂)** — exits street view and positions the globe camera at the matching location
- **Zoom out button (−)** — at Leaflet zoom level 4 or below, exits to the globe
- **Leaflet zoom-out** — zooming out past level 3 on the street map auto-exits to the globe

### Dark mode support

OpenStreetMap tiles are automatically filtered in dark mode (`brightness(0.65) contrast(1.15) saturate(0.85)`) to match the globe's dark aesthetic. The filter applies both with system-level dark mode and the app's manual theme toggle.

### CSP update

The Content-Security-Policy `img-src` directive now includes `https://*.tile.openstreetmap.org` to allow loading map tiles.

## Fixed during testing

The `requestAnimationFrame`-based animation loop does not run when the browser tab is hidden or in the background (a known browser behavior). This meant that `camDist` — which interpolates smoothly toward `targetDist` at 15% per frame — would never converge when the tab wasn't visible. Consecutive cluster clicks would all read the same stale `camDist` and compute the same zoom target, making it impossible to reach the street view transition threshold.

Fixed by:
1. Using `targetDist` instead of `camDist` when computing the next zoom level on cluster click, so consecutive clicks compound correctly regardless of animation state
2. Snapping camera position to target values (`rotX = targetRotX; rotY = targetRotY; camDist = targetDist`) in the `scheduleRecluster` fallback timer, so the globe visually updates even when rAF is stalled
