## Motivation

When reviewing unidentified faces on the faces review page, users often click "Enlarge" to see the full photo for context — especially when a face crop is ambiguous (turned, blurry, or dark). Previously, the enlarged lightbox only offered "Not a person", "Unknown person", and "Trash photo" actions. To actually name the face, users had to close the lightbox and go back to the small card's name picker. This extra step was friction in the most common workflow: enlarge to identify, then name.

## What changed

The faces review lightbox now includes a "Who is this?" person picker button in the action bar, styled as the primary action. Clicking it opens the same name search/selection dropdown used on the cards — with search, existing names, and "+ New person" — so users can name a face directly while viewing the full photo.

The picker resets to "Who is this?" each time the lightbox opens, and closes automatically when the lightbox closes. When a name is chosen from the lightbox, it triggers the same naming flow as the card picker: the API call is made, the card is removed from the grid, and any "Also looks like" match groups appear as usual.

### Files changed

- `src/photo_search.py` — added `<div class="lightbox-picker">` container to the lightbox header in the faces review template.
- `web/js/faces-review.js` — created a lightbox-scoped `createPersonPicker` instance, wired to the naming API. Resets on open, closes on lightbox close.
- `web/css/faces-review.css` — styled the lightbox picker trigger as a primary accent-colored button matching the lightbox action bar.
