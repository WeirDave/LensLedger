## Why this release

On the People page, each "Also looks like …" suggestion group has an
"⛶ Enlarge" button under every thumbnail. Choosing a different name for the
face in that enlarged view saved the new name, but the thumbnail stayed in
the group with its checkbox still ticked. Clicking "Confirm all" afterwards
sent that face along with the rest and assigned it to the suggested person,
replacing the name that had just been chosen and adding the suggested person
to the photo as well. The same applied to "Unknown person", "Not a person" and
"Move to Trash" in the enlarged view.

## What changed

- A face settled from the enlarged view — named, marked "Unknown person" or
  "Not a person", or moved to Trash — is now removed from its "Also looks
  like …" group as soon as the action succeeds.
- "Confirm all" and "Confirm all remaining" therefore only confirm the faces
  still shown in the group.
- When the last face in a group is settled this way, the group closes.

Faces already reassigned by "Confirm all" before this release keep the
suggested person; open the photo and correct the name to fix them.

## Verified

- Full test suite: 210 tests, all passing, on Python 3.12.10.
- Checked in the browser against a generated test library with a synthetic
  three-face suggestion group and the server calls stubbed: naming the first
  face from the enlarged view and marking the second "Unknown person" removed
  both from the group, and "Confirm all" then sent only the third face.
  Moving the only face of a one-face group to Trash closed the group.
