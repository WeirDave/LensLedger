## Motivation

The Dev tools link was placed inline in the Navigation section of the hamburger menu, mixed in with the main app pages. WaxFrame Professional puts its Dev Tools in a separate collapsible "Advanced" section — a better pattern since it keeps dev-only items out of the way for normal use.

## What changed

Moved the Dev tools link from the Navigation section to its own **Advanced** collapsible section in the hamburger menu, positioned after Help & Support. The menu structure now matches WaxFrame Professional's layout:

1. **Navigation** (open) — Home, Scan photos, People review, etc.
2. **Help & Support** (collapsed)
3. **Advanced** (collapsed) — Dev tools

## Verified

- Test suite: 88 tests passed.
- Browser verification: opened hamburger menu on Settings page, confirmed Dev tools appears under the Advanced section with the correct icon and active-state highlighting.
