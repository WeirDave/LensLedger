## Unified "People" naming

The feature area previously called "Faces Review", "Faces", or "People Review" in different parts of the app is now consistently called **People** everywhere — URLs, page titles, navigation, buttons, progress metrics, and all user-facing text. Old URLs (`/faces-review`, `/people-review`) redirect with 301s so bookmarks and links keep working.

## Skip tracking stops face recycling

Dismissing a group of faces now records the decision server-side (a `skipped_at` timestamp on each face embedding), so those faces stop reappearing across page reloads, browser sessions, and devices. Previously, dismissed faces lived only in a client-side `pending` Set and came back on every reload.

The similarity threshold for finding "also looks like" matches was also raised from 0.65 to 0.72. This cuts down on low-confidence suggestions that were repeatedly surfacing the same people (the user's own face, family members, and a handful of recurring contacts) as one-off matches that never stuck.

A **Show skipped** button in the topbar lets you bring back all skipped faces if you change your mind.

## Quick tag mode

The People page topbar now has a **Quick tag** button. Clicking it enters quick-tag mode:

1. A bar appears with a person picker — choose who you're tagging.
2. Click any face card to instantly tag it as that person. The card disappears and a running count shows how many you've tagged.
3. If the tag triggers "also looks like" match suggestions, they appear as usual.
4. Click **Done** to exit quick-tag mode.

In quick-tag mode, the per-card info panel and action buttons are hidden so the grid is denser and faster to work through.

## Bulk select & assign

The topbar also has a **Select** button for bulk operations:

1. Enter select mode — each card gets a circular checkbox overlay.
2. Click cards to toggle selection; a count updates in the bar.
3. Use the **Assign to…** picker to name all selected faces at once.
4. **Clear** deselects all without leaving the mode.

## Clickable face boxes in the photo viewer

When viewing a photo that has detected faces, all face locations now appear as overlay boxes on the image:

- **Named faces** show a solid border with a label on hover.
- **Unnamed faces** show a dashed border and "Click to name" on hover. Clicking opens a person picker right at the face box so you can tag it without leaving the viewer.

This replaces the old single-face "focused-face-box" overlay when multiple faces are available.
