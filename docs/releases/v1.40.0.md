# Videos show a picture in the thumbnail strip

## Why this release

- Videos in the thumbnail strip under the photo viewer were drawn as a dark tile with the text "VIDEO". With several videos in a row there was no way to tell them apart without opening each one.

## What changed

### Thumbnail strip

- Each video now shows a still picture from the video, with a small play button over it. Photos look as before.
- A video whose picture cannot be read keeps the dark tile with the "VIDEO" label.
- Nothing needs to be turned on. The pictures appear the next time the strip is shown.

### How the picture is made

- LensLedger asks Windows for the same preview Explorer shows for the file, so it works for whatever video formats and codecs are installed on the computer. If Windows has no preview for a file, OpenCV is used when it is installed (it comes with the optional face location packages).
- The picture is stored as a small JPEG in the thumbnail folder (`Thumbnails`) next to the photo thumbnails, made once per video and rebuilt if the video file changes. The folder stays limited to 1 GB in total, and anything removed is made again when needed.
- Videos are only read, never modified.

## Verified

- Full test suite: 655 tests, all passing.
- New tests cover a video thumbnail being made once and reused, a video with no readable picture returning no thumbnail so the label is shown, and a real generated video file producing a frame with the right colours.
- Browser check of the thumbnail strip in the light and dark themes, using a generated library with generated videos.
