## Quick guide — library management documentation

The in-app Quick guide (accessible from the menu on every page) previously covered tagging, keyboard shortcuts, and supported image formats, but had no mention of library management.

Added a new "Library management" section to the guide covering:

- How to add a library and the database location choice
- Switching between libraries
- Relocating a library (e.g. moving photos from a USB drive to a hard drive)
- When to store the database inside the photo folder vs. the default app data folder
