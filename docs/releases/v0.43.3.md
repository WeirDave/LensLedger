# LensLedger v0.43.3 — Instant startup message in launcher console

## Context

v0.42.2 added a "Starting LensLedger..." echo to `Start LensLedger.cmd`,
but placed it just before the `python src\photo_search.py` line. The
console window was still blank for several seconds because a PowerShell
command on line 51 (which kills any previous LensLedger server on port
5309) runs before the echo and takes noticeable time to complete.

## What changed

Moved the three echo lines (`echo.` / `echo Starting LensLedger...` /
`echo.`) to immediately after `@echo off`, `title LensLedger`, and
`cd /d "%~dp0"` — the very first output the user sees. The message now
appears the instant the console window opens, well before the stale-server
cleanup, Python check, dependency check, or any other slow step.

## Verified

- **Test suite:** 79 tests, all passing.
- **Manual review:** confirmed the echo lines are at the top of the script,
  before all slow operations.
