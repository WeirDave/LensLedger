LensLedger now makes a person's photo view explain exactly what you are seeing.

## Included

- Per-person counts for confirmed photos and any face matches awaiting review
- A direct **Review possible matches** link for that specific person
- Exact-face-box counts and a highlight around the identified face while you
  browse that person's confirmed photos, when the catalog has an exact face
  location
- Continued full group-photo support: every confirmed person remains linked to
  the same photo and appears in their own People view

## Notes

Older or manually confirmed photo links can be valid without an exact face
location. LensLedger shows the photo and all confirmed people, but only draws a
face box when it has stored, verified coordinates.

## Verified

- Automated server coverage verifies the person summary, person-specific review
  link, and exact face coordinates returned to the photo viewer.
- The full automated Windows test suite passes on Python 3.11 and Python 3.14.
