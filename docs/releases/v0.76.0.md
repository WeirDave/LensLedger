## Motivation

The two-page face identification workflow (Name Faces + Review People) was
confusing — users didn't know which tool to use or when to switch between
them. The "Confirm all remaining" threshold (25 confirmed + 75% cohesion) was
an engineering guess, not grounded in real data.

Analysis of the production database showed that out of 58 people with review
history, 55 had 100% accuracy from the very first suggestion. The system
rarely makes mistakes, and when it does, it's apparent early (Anita
Schwartzman: 26 wrong out of 33, errors throughout). A threshold of 10
confirmed with 100% accuracy is both safe and fast.

## What changed

### Renamed "Name faces" to "People review"

The page at `/faces-review` is now called "People review" everywhere:
navigation menu, page title, header, user manual, server log messages, and
cross-references from other pages.

### Removed "Review people" from navigation

The separate "Review people" page (`/people-review`) has been removed from
the navigation menu. The route and page still work (accessible by URL) for
backwards compatibility, but users are directed to the consolidated
"People review" page for all face identification tasks.

### Accuracy-based "Confirm all remaining" threshold

The button now appears when:
- **10+ confirmed faces** (was 25)
- **100% accuracy** (was 75% cohesion)

This is grounded in real data: the system achieves 100% accuracy for most
people within the first few suggestions. If accuracy drops below 100%, the
user sees the accuracy percentage and keeps reviewing.

### Progress feedback in match groups

Match group headers now show progress toward the confirm-all threshold:
- `"5/10 confirmed — keep going"` — below 10, keep naming
- `"ready to confirm all"` — 10+ confirmed with 100% accuracy
- `"87% accuracy — review more to improve"` — accuracy below 100%

This tells users when to stop reviewing and let the system handle the rest.

### Updated user manual

The manual's "People and Faces" section now:
- Describes a single workflow instead of two stages
- Includes a "When to stop" section explaining the progress indicators
- Updates the "Confirm all remaining" section with the new threshold
- Fixes cross-references (Publish photos link, etc.)

## Verified

- **Test suite**: 80 tests, all passed.
