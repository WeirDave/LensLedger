# Launcher keeps Python and its packages current

## Why this release

- The launcher decided whether to install packages with a test written into the launcher itself: Pillow at version 13 or later, and pillow-heif present. A change to any other package, or to a different minimum, was never noticed, and an old installation kept running with whatever it already had.
- The launcher used the first `python` on the PATH. A computer with an older Python ahead of a newer one ran on the older one, and packages installed for the newer one were not the ones in use.
- The launcher said Python 3.11 or newer was needed, but only checked that some `python` existed.

## What changed

### Python

- **Start LensLedger.cmd** and **Install LensLedger.cmd** choose the newest Python installed (through the Windows `py` launcher), provided it is 3.11 or newer and a final release. If `py` is not available, or nothing suitable is found, the `python` on the PATH is used as before.
- A Python older than 3.11 is reported with the version found, where it is, and a link to download a current one. The launch then stops.

### Packages

- Each launch, and each restart after an update, runs a new check (`src\environment_check.py`) that reads `requirements.txt`, the same file an update replaces. A package that is not installed, is outside the listed versions, or is registered but cannot be loaded is installed or updated, and the output names each one. The launch stops with an error if that fails.
- A new or raised requirement in a future release therefore needs no change to the launcher. The optional packages for meaning search and face detection, which stay commented out in the file, are still installed from **Settings** only.
- An installation whose packages already meet the file starts without contacting the network.

### Documentation

- The manual and the README describe these checks. The old statement that the launcher installs Pillow 13 was replaced.

## Not changed

- No setting, database change or change to how photos are scanned, tagged or published.
- Python itself is not installed or upgraded by the launcher. When a newer Python is installed, the launcher uses it and brings its packages up to date.

## Verified

- Test suite: 603 tests, all passing, including 17 new ones. They cover version comparison, reading the requirements file, a raised minimum and a new package being noticed, a package that cannot be loaded, each exit code of the check, and the launchers calling the check on launch and on restart with no bare `python`.
- The interpreter choice was run in a Command Prompt on a computer with two Pythons installed and selected the newer one. The package step was run on that Python, which had Pillow 12.3.0, and updated it to 13.0.0; a second run made no changes.
