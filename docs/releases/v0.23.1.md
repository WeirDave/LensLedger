A quick follow-up: large photos no longer fail OCR, and the project's file
layout got a cleanup with no effect on how LensLedger looks or runs.

## Large images no longer fail OCR

Windows OCR rejects any image wider or taller than its built-in maximum
(10,000px), and large panoramas or scans were hitting that limit as a silent
per-photo error — "Image dimensions are too large." LensLedger now decodes
oversized images at a scaled-down size before recognition instead of failing,
so those photos get OCR text like everything else.

## Project layout cleanup

All Python modules now live under `src/`, and `static/` is split into
`static/css/` and `static/js/` instead of one mixed folder. This is purely
internal — it doesn't change how the app looks, runs, or self-updates.

## Verified

- Full automated suite (39 tests) passing after the layout move, including a
  simulated release build validated through the real installer checks and
  launched standalone from a scratch directory.
- OCR fix verified against a synthetic oversized test image (previously
  failed, now recognizes text correctly) and confirmed normal-sized images
  are unaffected.
