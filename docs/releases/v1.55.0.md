# The main page says when imported folders still need a name

## Why this release

- Auto-import runs in the background and names folders only for the date.
- Nothing showed that a new folder was waiting for a name unless the **Auto-import photos** page was opened.

## What changed

### Main page

- A notice appears under the search controls when a folder filled by auto-import is still named only for a date. It shows up to six of the photos, taken from the waiting folders.
- **Name folders** opens **Name your folders** on the **Auto-import photos** page.
- **Not now** hides the notice in that browser. It returns when auto-import fills another folder, and then counts only the new ones.
- The notice appears within about 20 seconds of an import while the page is open, and the photos appear once the scan has picked them up.
- It clears when each folder has been renamed or has a name saved to apply. A saved name that cannot be applied brings it back.
- Folders named by an override rule, rather than for a date, do not raise it. The People Index does not show it.

### Auto-import photos page

- **Name your folders** lists folders still needing a name first. Up to 100 of them are listed however long ago they were filled, followed by the 20 most recently filled folders that have a name.

### Renaming

- Renaming a folder with many photos is faster in a large library. The search table is cleared for all of the folder's photos in one pass.

## Verified

- Full test suite: 789 tests, all passing.
- Browser, on a generated test library: the notice in light and dark themes, at phone width and with a photo open, **Name folders**, and **Not now** across a reload.
