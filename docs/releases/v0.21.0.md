LensLedger now shows exactly which face produced every People-review suggestion.

A responsive yellow box follows the matched face in both gallery cards and the
enlarged-photo view. This removes the ambiguity of reviewing a whole group photo
without knowing which person LensLedger is asking about. When a recovered legacy
match cannot be localized with high confidence, LensLedger says so instead of
highlighting a guessed face.

This release also fixes the learning behavior that caused the misleading queues.
Older photo-level confirmations sometimes named somebody in a group photo without
identifying their exact face. If the photographer appeared consistently in those
photos, the old learner could accidentally build the friend's profile from the
photographer. Multi-person photos now train a profile only after an exact face has
been confirmed, and highly similar profiles are quarantined from new suggestions.

## Included

- Exact face boxes in People-review cards and enlarged photos
- Responsive labels that remain readable near image edges
- Schema 7 storage for normalized face coordinates and localization confidence
- Review API support for exact matched-face coordinates
- Optional local recovery of boxes from compatible legacy embeddings
- Strong similarity and ambiguity thresholds that reject uncertain recovery
- Safe single-face or exact-face-only identity training
- Similar-profile quarantine to contain historical naming mistakes
- Explicit separate-model licensing documentation; no face model is bundled
