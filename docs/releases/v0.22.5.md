LensLedger now closes the gap between its managed updater and older desktop
shortcuts.

When a pre-managed copy is migrated, LensLedger preserves its original
`Start LensLedger.cmd` as a backup and safely turns the existing launcher into
a handoff to the managed per-user installation. That means an old shortcut no
longer starts an obsolete application copy or replaces the current server with
one; it launches the installed, updateable LensLedger instead.

The updater remembers each explicitly adopted old launcher and rechecks it on
future updates. If an old folder has moved or is unavailable, the managed
update still completes normally.

This release also makes the GitHub release workflow verify that the version in
`product.py` matches the pushed tag and that matching release notes exist before
it publishes a ZIP.

## Verified

- Automated updater coverage preserves the old launcher, creates the managed
  handoff, and restores the handoff if a registered legacy launcher is brought
  back.
