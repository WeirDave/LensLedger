# LensLedger v0.50.0 — Automatic folder watching

## Motivation

As a photo collection grows and new subfolders are added, the user must manually re-run the scan to pick them up. There is no live watching or automatic detection.

## What changed

### Scheduled incremental scanning

A new `FolderWatcher` class (`src/folder_watcher.py`) provides a background timer thread that triggers an incremental library scan at a configurable interval. This is a scheduled-scan approach rather than filesystem-notification-based, which avoids the following problems:

- Cloud-synced folders (OneDrive, Dropbox) generate filesystem events for placeholder files that are not actually downloaded yet
- The existing `is_cloud_placeholder()` logic and content-hash reconciliation already handle everything the watcher needs
- Large libraries make frequent full scans expensive, but the incremental scan is already fast for unchanged files

### How it works

1. At server startup, the watcher reads the `watch` section from `settings.json`
2. If `enabled` is true, it starts a daemon timer thread that fires every `interval_minutes` minutes
3. On each tick, it checks whether a manual scan is already running (avoids conflicts) and runs `scan_library()` if not
4. The watcher skips ticks while a manual scan is active
5. Changing settings via the Settings page starts, stops, or updates the watcher immediately

### Configuration

Via the Settings page (Folder watching section):
- **Enable automatic folder watching** — toggle on/off
- **Check interval** — 5 to 1440 minutes (default 30)

### API

- `GET /api/watcher/status` — returns `{enabled, interval_minutes}`
