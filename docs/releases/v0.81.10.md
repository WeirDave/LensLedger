## What happened

The file path displayed at the bottom of the enlarged lightbox on the People review (faces) page was garbled — folder separators and dashes appeared in wrong positions, making the path unreadable. For example, `2017/2017_09_24 - Live Concert/2017_09_24_20_04_05_PM.jpg` would render as something like `Live Concert\2017_08_24_20_04_05_PM.jpg - 24_09_2017/2017`.

## What changed

The `.lightbox-path-text` CSS class in `web/css/faces-review.css` used `direction: rtl` to make `text-overflow: ellipsis` truncate from the left (showing the filename end rather than the folder beginning when the path is too long). However, `direction: rtl` activates the Unicode Bidirectional Algorithm, which reorders directionally neutral characters like `/`, `-`, and `_` according to RTL rules — scrambling file paths that contain those characters.

Changed `direction: rtl` to `direction: ltr`. The path now renders correctly.

- Full test suite: 88 tests passed.
- Visually verified in the browser: opened the faces review lightbox and confirmed the path at the bottom displays correctly in left-to-right order.
