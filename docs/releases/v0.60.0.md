# LensLedger v0.60.0

## Settings page shows per-library database path

The Settings page previously showed only the general application data folder (`%LOCALAPPDATA%\LensLedger`). Since databases now live inside each library's `.LensLedger` folder by default, this was misleading — users couldn't tell where their actual database was stored.

The Database section now shows two lines:
- **Database:** the full path to the current library's SQLite file (e.g. `C:\Dropbox\Photos\.LensLedger\LensLedger-Photos.sqlite3`)
- **Application data:** the general settings/config folder in AppData

This makes it immediately clear where the index lives, which is especially useful when moving a library to another drive or backing it up.
