## People Index — nav access, alphabet jump bar, and film-strip dividers

The People directory page (formerly reached only by searching with scope=People on the home page) is now directly accessible from the navigation menu as **People Index**. The heading, page title, and back-links all use the new name.

## Alphabet jump bar

A sticky alphabet bar sits at the top of the People Index. Letters with at least one person are clickable; letters with no entries are greyed out. Clicking a letter smooth-scrolls to that section within the page's scroll container.

The scroll JavaScript was moved from an inline `<script>` to an external file (`web/js/alpha-bar.js`) to comply with the Content Security Policy `script-src 'self'` directive, which was blocking the inline version.

## Film-strip letter dividers

Each letter section is introduced by a large bold letter followed by an SVG film strip — a horizontal bar with sprocket-hole perforations along the top and bottom edges, keeping with LensLedger's retro photography theme. The film strip uses CSS custom properties so it adapts to both light and dark themes.
