# Menu skipped by Tab when closed, focus moves into it

## Why this release

- The slide-in menu sits off-screen when closed, but its links and buttons stayed in the Tab order, so keyboard users moved through about twenty invisible controls.
- Opening the menu did not move focus into it, and the menu button did not report whether the menu was open.
- The menu and the viewer's filmstrip had no labels for screen readers.

## What changed

### Menu (every page)

- While the menu is closed, none of its links or buttons can be reached with the Tab key.
- Opening the menu moves focus to its close button. Closing it with the close button or the Escape key returns focus to the menu button.
- The menu button reports whether the menu is open.
- The menu is labelled "Main menu".

### Photo viewer

- The filmstrip is labelled "Photos".

## Not changed

- The menu's contents, appearance and animation, and how it opens and closes with the mouse.

## Verified

- Full test suite: 542 tests, all passing.
- Browser check on the photo viewer and the Publish page: the closed menu is not focusable, opening moves focus to the close button, and both the close button and the Escape key return focus to the menu button.
