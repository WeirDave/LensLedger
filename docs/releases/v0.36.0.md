LensLedger's viewer was built for desktop — the two-column layout with the
sidebar always visible meant that on phones and small tablets the photo was
squeezed into a tiny column, the toolbar overflowed, and the filmstrip
thumbnails were too large for the available space. This release makes the
viewer fully usable on mobile screens.

## What changed

### Slide-in sidebar drawer

On viewports under 768px, the sidebar is no longer part of the grid layout.
Instead it becomes a fixed-position panel that slides in from the right edge
when the user taps the ⓘ button on the photo stage. A semi-transparent
backdrop overlay appears behind it, and tapping the backdrop or pressing
Escape closes the drawer. The photo stage takes the full viewport width.

### Compact layout

- **Toolbar** wraps its controls instead of overflowing on narrow screens.
- **Header** uses reduced padding and auto min-height so it doesn't waste
  vertical space.
- **Filmstrip** uses tighter spacing and smaller thumbnails (130px wide,
  100px tall) to fit more photos on screen.

### Toggle button

A circular ⓘ button is positioned in the top-right corner of the photo
stage. It's hidden on desktop (where the sidebar is always visible) and
shown only on mobile via the media query.

### Event handling

- The sidebar toggle button, backdrop click, and Escape key all wire up in
  `viewer.js` to open/close the sidebar and backdrop in sync.
- Escape also closes the sidebar before clearing batch selection, so the
  two features compose correctly.

## Verified

- Test suite: 79 tests, all passing.
- Browser testing at 375x812 (mobile preset): photo fills viewport width,
  toolbar wraps cleanly, filmstrip thumbnails are compact, ⓘ button visible
  in top-right. Opened sidebar via toggle — slides in from right with
  backdrop visible. Closed via backdrop click — sidebar slides out. Switched
  back to desktop (1280x800) — sidebar is inline, toggle button hidden,
  layout unchanged from before.
