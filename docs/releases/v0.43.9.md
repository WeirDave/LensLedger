# LensLedger v0.43.9 — Browser-tab reminder only on restart

## Context

v0.43.7 added a "close the previous browser tab" reminder to the console
startup message, but it appeared on every launch — including fresh starts
where there's no old tab to close. The message was only relevant after a
restart triggered by the stale-version banner.

## What changed

The updater now passes `--restarted` to `Start LensLedger.cmd` when
launching after a restart (detected by the presence of `old_window_pid`).
The .cmd forwards all arguments to Python via `%*`. The early startup
print in `photo_search.py` checks for `--restarted` in `sys.argv` and
only shows the browser-tab reminder when it's present. On a normal launch,
only "Loading LensLedger..." appears.

- **Test suite:** 79 tests, all passing.
