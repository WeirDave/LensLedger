LensLedger now makes the alternate-name format explicit wherever you edit a
person: enter one or more alternate names separated by commas.

## Included

- A clear comma-separator instruction in the People page and **Edit names**
  dialog
- An example such as `Dave, David, Me`
- Matching instructions in the README

## Verified

- Server coverage confirms the People page contains the separator guidance.
- The full automated Windows test suite passes on Python 3.11 and Python 3.14.
