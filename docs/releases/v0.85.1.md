## Alphabet bar and film-strip divider refinements

### Alphabet bar flush with header

The alphabet jump bar was floating below the page header with a visible gap. It is now the first element inside the scroll container with a negative top margin that pulls it flush against the header border, using the same header background color and a bottom border for visual continuity.

### Film-strip dividers improved

The film-strip SVG dividers under each letter header were redesigned:

- Shortened to a 200px decorative accent instead of stretching full-width.
- Dark film-stock brown (`#3a3226`) with darker sprocket holes (`#1a1610`) for a more realistic 35mm film look.
- Proportioned sprocket holes with proper spacing.

### Scroll offset tuned

Adjusted the alphabet-bar click-to-jump scroll offset to account for the new flush layout, so letter headers land just below the sticky alphabet bar.

- Browser verification: alphabet bar flush against header, film-strip accent under letter headers, click-to-jump scrolling M and S sections confirmed working.
