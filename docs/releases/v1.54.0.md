# Folders filled by Auto-import can be named inside LensLedger

## Why this release

- Auto-import sorts new photos into folders named for the date, such as `2026_08_28`.
- LensLedger offered no way to add what the photos were to the folder name. Renaming had to be done outside the app, followed by a scan.

## What changed

### Auto-import photos page

- A **Name your folders** panel, directly under **Status**, lists up to 20 folders that auto-import has added photos to, most recent first. Folders without a description are outlined.
- Each folder shows its item count, the date of the latest import, and up to six previews once the photos are scanned. **View photos** opens the folder's photos, for folders inside the open library.
- Typing a description and clicking **Rename** adds it after the date: `2026_08_28` becomes `2026_08_28 - Beach day`. The field starts with the current description, and clearing it restores the date-only name.
- Descriptions already used in the list are suggested while typing, for an event that covers several days.
- After **Run now** imports photos, the page scrolls to the panel.

### What a rename keeps

- The folder is renamed on disk, and each library that contains it is updated at the same time. If either step fails, neither is applied.
- Tags, people, ratings, subjects, removed tags, recognized text, scan results, safety copies and Review Bin entries stay with the photos. A photo restored from the Review Bin returns to the renamed folder.
- Automatic folder tags follow the new name. Folder tags added by hand are kept.
- Later imports for the same date go into the renamed folder.
- A folder renamed outside LensLedger is still listed when its name begins with the full date.

### When renaming is unavailable

- **Rename** is unavailable while a scan, tag writing or publishing is running, including the scan that follows an import. The panel names the running work, and the button becomes available when it has finished.
- A name that is already taken, a name containing characters Windows does not allow, a folder that is a photo library, and a folder that holds the auto-import source folder are refused with an explanation.

## Fixed during testing

- Scrolling to the new panel after **Run now** left its heading hidden behind the page header. The panel now stops below the header.
- The notice about the scan that follows an import could take up to 15 seconds to appear. The panel now checks again a few seconds after an import.

## Verified

- Full test suite: 769 tests, all passing.
- Browser, on a generated test library: the panel in light and dark themes and at phone width, an import with **Run now**, and a rename.
