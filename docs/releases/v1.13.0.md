## Why this release

The same person can end up in People under more than one name: a typo when
tagging, an initial in one place and the full first name in another, a
nickname, or a name with and without an accent. "Merge people" could combine
them, but only once the duplicates had been spotted by scrolling through
the whole list.

## What changed

**People page — "Find duplicates"**

A new **Find duplicates** button sits in the People page toolbar, next to
"Merge people". It opens a list of pairs that may be the same person, each
with both card photos, their confirmed photo counts and the reason the pair
was listed:

- **Same name apart from punctuation, accents or capitals** — for example
  "Zoë O'Hara" and "zoe o hara".
- **An initial matches the full name** — "J. Robert Thornton" and
  "James Robert Thornton".
- **One name is part of the other** — "Mira Castellan" and
  "Mira Jo Castellan". A first name on its own is only matched when at most
  one other person shares it.
- **Names are spelled almost the same** — "Katherine" and "Kathrine".
- **Their learned faces look alike** — the face profiles LensLedger has
  learned from confirmed photos are close enough to suggest one person.
  This catches a nickname or a completely different spelling.

Alternate names count as well as primary names. Pairs matching on both
name and face are listed first.

Each pair offers:

- **Keep "name"** (one button for each name) — merges the other record into
  it, exactly as "Merge people" does: the other name becomes an alternate
  name, photo links are combined and confirmed JPEG metadata is updated with
  a safety backup.
- **Not the same person** — hides the pair from the list for good.

Some pairs are never listed:

- Two people confirmed in the same photo.
- Names that differ only by a generational suffix, such as "Jr" and "Sr".

The People page refreshes when the list is closed after a merge.

## Database

Schema version 21 adds a table recording pairs marked "Not the same
person". It is created automatically on first start; nothing else changes.
If either person is later deleted or merged, the record is removed with it.

## Verified

- Full test suite, all passing.
- New tests cover each kind of name match, the Jr/Sr exclusion, a common
  first name that is not matched, face-profile matching, ordering, people
  confirmed in the same photo, and a dismissed pair staying dismissed —
  including through the server endpoints.
- Checked in the browser against a generated test library with invented
  names: the list, a "Not the same person" dismissal, and a merge that
  turned the other name into an alternate name, in both light and dark
  themes.
