# LensLedger v0.43.12 — Consistent headers across all pages

## Context

The Name faces and People review pages had headers that were laid out differently
from the main Photo library page. The version badge was positioned after the
navigation links instead of next to the logo, the theme toggle was in the middle
instead of at the far right, the unidentified faces count wasn't pushed to the
right side, and there was no hamburger menu button for navigation.

## What changed

Both the Name faces (`/faces-review`) and People review (`/people-review`) pages
now use the same header layout as the main page:

1. **Hamburger menu button** — replaces the inline quick-nav links, matching the
   main page's navigation pattern. The menu panel includes links to Photo library,
   the other review pages, Scan photos, and Photo map.
2. **Version badge** — moved to sit right after the logo and title, matching the
   main page.
3. **Theme toggle** — moved to the far right of the header, matching the main page.
4. **Progress/count and action button** — positioned between the spacer and theme
   toggle so they sit near the right side.

CSS was updated in both `faces-review.css` and `people-review.css` to add
`.menu-toggle` and `.menu-panel` styles matching `viewer.css`. JavaScript was
updated in both `faces-review.js` and `people-review.js` to handle menu
toggle/close behavior.

## Verified

- Test suite: 79 tests, all passing.
- Header element order confirmed via code review and read_page inspection.
