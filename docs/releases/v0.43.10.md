# LensLedger v0.43.10 — HEIC/HEIF metadata publishing

## Motivation

LensLedger could scan and index HEIC/HEIF images, but the metadata
publishing feature — writing people tags and descriptions back into the
image file — was restricted to JPEGs only. Attempting to publish metadata
for an HEIC photo produced the error "People metadata publishing requires
a JPEG."

ExifTool (the underlying tool LensLedger uses) fully supports writing
XMP and EXIF metadata to HEIC/HEIF files, and Pillow with pillow-heif
can decode their pixels for the safety hash verification. There was no
technical barrier — just a conservative allowlist.

## What changed

- Added `.heic` and `.heif` to `PUBLISHABLE_EXTENSIONS` in
  `src/photo_search.py`, enabling both people-metadata publishing and
  general metadata publishing for these file types.
- Updated error messages from JPEG-specific wording to a generic
  "Publishing is not supported for this file type" message that includes
  the filename.

## Verified

- Test suite: 79 tests passed.
- ExifTool's WriteQuickTime module confirms full HEIC write support
  (XMP, EXIF, and the HEIC-specific metadata map).
- pillow-heif is already registered in `metadata_reader.py`, so the
  `pixel_hash` safety check works for HEIC files.
