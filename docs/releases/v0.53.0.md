# LensLedger v0.53.0 — Auto-ingest dedicated page

## Motivation

The camera upload auto-ingest pipeline was buried as a section inside the Settings page, making it feel like a preference toggle rather than a full workflow. The sorting rules had no documentation — users couldn't tell what `{year}/{year}_{month}_{day}` meant, what placeholders were available, or how rules interacted with the default date template.

## What changed

### New auto-ingest page (`/auto-ingest`)

A dedicated page with its own CSS and JS, accessible from the nav menu. Sections:

1. **Status dashboard** — live stats showing pipeline state, ingested count, duplicates skipped, and errors
2. **Pipeline configuration** — enable/disable toggle, source folder, destination folder with browse buttons
3. **Date sorting template** — customisable template with live preview showing where today's photos would go, and a full placeholder reference (`{year}`, `{month}`, `{day}`, `{hour}`, `{minute}`)
4. **Override rules** — clearly documented as optional filename-based overrides with explanation of how they interact with the date template
5. **Activity log** — scrollable recent activity showing every file the pipeline has processed, with action type, file paths, and timestamps

### Dedicated API endpoint

`POST /api/ingest/save` saves ingest configuration independently from general settings.

### Configurable default template

The date sorting template is now persisted in settings as `default_template` and passed through to the `IngestPipeline`. Previously hardcoded to `{year}/{year}_{month}_{day}`.

### Settings page cleanup

Removed the ingest section from the Settings page. Settings now contains only: libraries, scan preferences, meaning search model, display preferences, folder watching, and database import/export.

### Navigation

Added "Auto-ingest" link to the nav menu between "Photo map" and "Settings".

## New files

- `web/css/auto-ingest.css` — page styles
- `web/js/auto-ingest.js` — client-side logic for config, status polling, and activity log

## Verified

- Test suite: 79 tests passed
- Browser verification: auto-ingest page renders correctly with all sections, nav menu works, settings page no longer shows ingest section, no console errors
