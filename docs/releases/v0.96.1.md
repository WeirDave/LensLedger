Fixed the street map tiles rendering only in a portion of the viewport when first transitioning from the globe to street view.

## Root cause

When `enterStreetView()` removed the `hidden` attribute from `#streetMap` and immediately called `leafletMap.invalidateSize()`, the browser had not yet completed its layout reflow. Leaflet measured the container as having its pre-layout dimensions, so it only requested tiles for a fraction of the actual viewport.

## Fix

Wrapped the Leaflet initialization, `invalidateSize()`, `setView()`, and `updateStreetMarkers()` calls inside `setTimeout(fn, 0)`. This defers execution until after the browser completes the layout reflow triggered by removing the `hidden` attribute, ensuring Leaflet measures the full container dimensions.

## Verified

- Test suite: 101 tests passed
- Browser verification (dark mode): street view tiles fill the entire viewport on first transition, markers render correctly, photo detail panel works
- Verified on the user's primary server (port 5309) with 18,788 located photos
