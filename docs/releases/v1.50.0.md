# Face detection can re-scan every photo

## Why this release

- Meaning search has **Fill in missing** and **Re-scan everything**. Face detection had only **Scan for faces**, which skips photos already scanned, so there was no way to run face detection over the whole library again, for example after switching to the graphics-card runtime.

## What changed

### Scan your photos, Face detection

- A **Re-scan everything** button sits at the left of the **Face detection** card, next to **Pause** and **Scan for faces**. It asks for confirmation, then looks for faces in every photo again, including ones already scanned.
- Faces already found are kept as they are, together with any name or decision made in People. Only faces that were missed before are added.
- A photo whose stored faces have no recorded position, such as faces carried over from an import, is left unchanged, so nothing is duplicated.
- The button is disabled while face detection or **Run all scans** is running.
- **Scan for faces** is unchanged: it scans photos not yet scanned and tries again photos that failed last time. A separate **Fill in missing** button is not needed, because failed photos are already retried.
- The activity log names the run "Re-scan everything for faces".

### Manuals

- The user manual and the in-app manual describe both face-detection buttons.

## Verified

- Full test suite: 726 tests, all passing, including new tests for re-scan keeping existing faces and names, adding only missed faces, leaving photos with unpositioned faces alone, passing the mode through the server and rejecting an unknown mode.
