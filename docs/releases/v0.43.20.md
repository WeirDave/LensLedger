## Auto-reload on stale CSRF token

When the LensLedger server restarts (e.g. after an update), it generates a new CSRF token. Any browser tab still open from before the restart would have a stale token baked into its page data. Previously, clicking any action button (Save & publish, Find more matches, etc.) would fail with "invalid request token" — a confusing message that required the user to manually refresh.

Now, all three page scripts (photo library, people review, name faces) detect a 403 response from the server and automatically reload the page, which fetches a fresh CSRF token. The user sees a brief page reload instead of an error.

## Verified

- Test suite: 79 tests, all passing.
- Confirmed the `api()` function in all three JS files (viewer.js, people-review.js, faces-review.js) checks for `response.status === 403` and calls `location.reload()` before attempting to parse the response body.
