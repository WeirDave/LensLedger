# Pillow updated to version 13 for security fixes

## Why this release

- Pillow 12 and earlier have published security vulnerabilities, several rated critical or high. They affect how image files are decoded, including TIFF, GIF, BMP, PNG, WMF/EMF and PDF handling. All of them are fixed in Pillow 13.0.0.
- LensLedger limited Pillow to versions below 13, so none of these fixes could be installed.

## What changed

### Requirements

- `requirements.txt` now asks for Pillow 13.0 up to, but not including, 14.

### Start LensLedger.cmd

- At launch, **Start LensLedger.cmd** now checks the installed Pillow version as well as whether Pillow can be imported. An installation with an older Pillow runs the package install once and moves to Pillow 13. The same check runs after an in-app restart.
- An installation that already has Pillow 13 skips the install and does not contact the network.

## Verified

- Test suite: 546 tests, all passing, run against Pillow 13.0.0 with pillow-heif 1.8.1.
- Package check: `pip check` reports no broken requirements with Pillow 13.0.0 and pillow-heif 1.8.1.
