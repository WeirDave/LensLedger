## Motivation

The group tag picker added in v0.93.0 had two issues:

1. **Auto-open bug** — the dropdown opened immediately when the Edit Person modal loaded, hiding the Cancel and Save buttons. This was caused by the browser caching stale JavaScript (the `?v=` query parameter wasn't changing between edits), combined with overly complex deferred-handler logic that didn't solve the underlying problem.

2. **Keyboard navigation didn't work** — all interactive handlers (input, keydown, click) were deferred behind a `requestAnimationFrame` guard as part of debugging the auto-open bug, which meant they weren't attached in time for keyboard interaction.

## What changed

### Simplified group picker handlers

Removed the `groupPickerReady` flag and the `attachGroupHandlers()` deferred-attachment pattern. Event handlers are now attached directly during DOM construction, before the modal is added to the page — this is safe because events can't fire on elements not yet in the DOM tree.

### Full keyboard navigation

- **ArrowDown** opens the dropdown (highlighting the first item) or moves the highlight down
- **ArrowUp** moves the highlight up
- **Enter** selects the highlighted option, or creates a new group if text is typed and no highlight is active
- **Escape** closes the dropdown without closing the modal (fixed — see below)
- **Backspace** on an empty input removes the last tag
- **Tab** closes the dropdown and moves focus forward

### Fixed Escape key conflict

The document-level `keydown` handler unconditionally called `closeModal()` on Escape, overriding `stopPropagation()` from the group input handler. Fixed by adding a check in the document handler: if a `.group-tag-dropdown.open` element exists, it dispatches a custom `group-dropdown-close` event (which the picker listens for via its closure's `hideDropdown`) and returns early without closing the modal.

### Fixed mouse/keyboard highlight conflict

Changed dropdown option hover handling from `onmouseenter` (which fires when the dropdown re-renders under a stationary cursor, stealing the keyboard highlight) to `onmousemove` with a guard that only updates when the index actually changes.

## Verified

- Test suite: 88 tests passed.
- Browser verification:
  - Modal opens without auto-opening the dropdown
  - Clicking the group input opens the dropdown with all available groups
  - ArrowDown/Up navigates the dropdown, Enter selects
  - Typing filters the dropdown, "+ Create" option appears for new groups
  - Escape closes dropdown only (first press), then modal (second press)
  - Backspace removes the last tag when input is empty
  - Chips render correctly with × remove buttons
  - Tested in both light and dark themes
  - Tested on mobile viewport (375×812) — chips wrap properly, all controls accessible
