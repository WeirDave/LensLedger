## Motivation

LensLedger was Windows-only: the folder picker used a PowerShell `FolderBrowserDialog` that didn't work on macOS or Linux, and even on Windows the dialog appeared behind the browser window. The app also lacked basic accessibility features — no skip-navigation, no ARIA landmarks, and modals didn't manage focus. The faces review intro paragraph couldn't be dismissed once the user understood it.

## What changed

### Cross-platform folder and file pickers

The monolithic `choose_library_folder()` function has been replaced with a platform dispatcher and three platform-specific helpers:

- **Windows** — PowerShell `FolderBrowserDialog` with a `SetForegroundWindow` P/Invoke call that brings the dialog to the foreground, fixing the long-standing issue where the browse button appeared to do nothing because the dialog opened behind the browser.
- **macOS** — AppleScript `choose folder` via `osascript`.
- **Linux** — `zenity --file-selection` with a `kdialog` fallback.

A matching `choose_file()` function was added for the database import flow, replacing an inline PowerShell file dialog in `import_database()`.

Library root suggestions now detect macOS volumes (`/Volumes`) and Linux mount points (`/media`, `/run/media`, `/mnt`). The OCR feature shows a clear error message when attempted on a non-Windows platform.

### Accessibility

- **Skip-navigation link** — a "Skip to photos" link appears before the header, visible on keyboard focus, jumping directly to the photo grid.
- **ARIA landmarks** — `role="banner"` on `<header>`, `role="search"` on the search form.
- **Modal focus management** — `openModal()` saves the trigger element and auto-focuses the first interactive element inside the modal. `closeModal()` restores focus to the trigger. All modal close paths (X button, backdrop click, Escape key) use the same restoration logic.

### Dismissible faces review intro

The introductory paragraph on the People Review page is now a styled card with a "Got it, don't show again" button. Dismissal is persisted in `localStorage` so it stays hidden across sessions.

### Search placeholder improvement

The Meaning (semantic) search scope now shows an example-based placeholder — "Try: sunset over water, dog playing in snow" — instead of the generic instruction text, making the feature more approachable.

### README updates

- Platform badge updated from "Windows" to "Windows | macOS | Linux".
- Added a macOS / Linux quick start section with bash commands.
- Added a data location table showing default paths on all three platforms.
- Documented the native folder picker tools and the OCR platform limitation.

### Backlog replaced with roadmap

The ad-hoc bug backlog file has been replaced with a structured roadmap covering cross-platform packaging, accessibility, mobile experience, people review, and UI polish.

## Verified

- Test suite: 88 tests passed.
- Browser verification: confirmed skip-nav link appears on focus, semantic search placeholder shows examples, faces review intro card displays with dismiss button, viewer page loads with zero console errors, modal focus management works on close.
