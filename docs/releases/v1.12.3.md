## Why this release

"Write all tags", "Publish all" and single-photo writes could list two more
kinds of photo under "photos could not be written":

- `Not a valid JPG (looks more like a PNG)` — for a file whose extension
  does not match its contents, most often a screenshot or download saved as
  PNG but named `.jpg`. ExifTool checks the contents against the extension
  and refuses to write when they differ.
- `Error creating file` — for a photo whose file name is 243 characters or
  longer. ExifTool writes to a temporary file named after the photo with
  `_exiftool_tmp` added. For these names that temporary name passes the
  255-character limit Windows sets on a single file name, so it cannot be
  created.

## What changed

- **Such photos are written through a working copy.** When ExifTool refuses
  a photo for either reason, LensLedger copies it to a short name in the
  system's temporary folder. The copy gets the extension that matches the
  file's contents. LensLedger writes the tags into the copy, copies it back
  over the photo, and removes the working copy.
- **The photo keeps its name and its format.** A PNG named `.jpg` stays a
  PNG named `.jpg`, now with its tags embedded. Other programs that read the
  file's contents, rather than its extension, see the tags.
- **The same safeguards apply.** A verified safety copy is taken first, and
  the pixels are compared afterwards. The photo is restored from the safety
  copy if anything fails.
- Photos that can be written where they are take the usual direct path, and
  no copy is made.

## Verified

- Full test suite: 249 tests, all passing. Real settings and library-state
  files were unchanged by the run.
- Two new tests, each confirmed to fail without the change:
  - A PNG saved with a `.jpg` name. "Write all tags" writes it without a
    failure or a sidecar, the description and keywords read back, the pixels
    are identical, the file is still a PNG, and no working copy is left in
    the folder.
  - A photo with a 250-character file name, with the same checks.
- The name-length limit was confirmed directly: with the bundled ExifTool,
  names of 240 characters write, and names of 245 and 250 characters fail
  with "Error creating file".
