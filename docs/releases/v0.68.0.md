## Motivation

When reviewing face suggestions on the People Review or Name Faces pages,
users could enlarge a photo to see the full image and the highlighted face
box. However, if the face was small — a person in the background of a group
shot, for example — the enlarged view still wasn't detailed enough to
confidently identify who it was. The only option was to mark it as "Unknown
person" and move on.

The main photo viewer already had full scroll-wheel zoom and drag-to-pan,
but the review lightboxes did not.

## What changed

Both the Name Faces and People Review lightboxes now support the same zoom
and pan interactions as the main viewer:

- **Scroll wheel** zooms in and out (1x to 20x), centered on the cursor
  position.
- **Click and drag** pans the image while zoomed in.
- **Triple-click** toggles between 1x and 3x zoom.
- A **zoom level badge** and **Reset zoom button** appear automatically
  when zoomed past 1x.
- The face-box overlay repositions correctly as you zoom and pan.
- Zoom resets automatically when closing the lightbox or opening a
  different photo.

The zoom logic is shared via a new `web/js/lightbox-zoom.js` module
included by both pages, keeping the implementation DRY with the existing
viewer zoom.

## Verified

- Test suite: 80 tests, all passing.
- Server starts cleanly on both review pages with no JS console errors.
- Lightbox zoom script loads and initializes correctly on Name Faces and
  People Review pages.
