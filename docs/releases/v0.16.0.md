LensLedger now has a clean, distributable home that contains the application —
not its owner's photo library.

This release moves every new user's databases, settings, safety copies, face
data, and review-bin files into that user's local LensLedger data directory.
The repository and release ZIP intentionally contain no database, photo,
personal annotation CSV, face vector, log, or absolute library path.

The first database toolkit is included. It can create a fresh catalog, report
schema and library status, run SQLite integrity and foreign-key checks, migrate
older databases, build a verified online backup, and reconstruct full-text
search. New scanner tests prove both fresh database creation and incremental
rescanning.

The README follows the same release-oriented format as WD Wireless Tools: clear
product positioning, privacy and safety promises, a Windows quick start,
maintenance commands, development checks, release badges, and a direct link to
the latest versioned ZIP.

## Included

- Empty-on-install, per-user SQLite storage
- Incremental photo and video indexing
- Local search, people review, OCR, and metadata inspection
- Explicit JPEG metadata publication with safety copies and pixel verification
- Database initialization, status, verification, migration, backup, and search rebuild tools
- MIT license and retained ExifTool third-party notices
- Windows CI on Python 3.11 and 3.14

## Verified

- Fresh database creation produces schema version 1 with zero assets.
- A synthetic library's first scan adds one asset and its second scan skips it unchanged.
- Online database backups pass SQLite integrity and foreign-key checks.
- All Python application and test sources compile successfully.
