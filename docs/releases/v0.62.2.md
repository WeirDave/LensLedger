# LensLedger v0.62.2

## Auto-import per-file console logging

The auto-import pipeline only logged a single summary line after each check, and stayed completely silent when nothing was found. This made it look like nothing was happening.

Now every action is logged individually:

```
  [2026-08-28 01:24:08 PM] Auto-import: checking for new photos
  [2026-08-28 01:24:10 PM] Auto-import: imported IMG_4521.jpg → 2026/2026_08_22
  [2026-08-28 01:24:11 PM] Auto-import: imported IMG_4522.jpg → 2026/2026_08_22
  [2026-08-28 01:24:12 PM] Auto-import: skipped duplicate — IMG_4520.jpg
  [2026-08-28 01:24:12 PM] Auto-import: 2 imported, 1 duplicates, 0 errors
```

When nothing is found, it now says so explicitly:

```
  [2026-08-28 01:34:08 PM] Auto-import: checking for new photos
  [2026-08-28 01:34:09 PM] Auto-import: no new photos found
```

Errors also log per-file with the specific error message.
