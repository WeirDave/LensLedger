# Folder names entered during a scan are saved and applied afterwards

## Why this release

- On the **Auto-import photos** page, **Rename** under **Name your folders** was unavailable while a scan, tag writing or publishing was running.
- A scan starts a few seconds after every import, so a new folder could not be named until it had finished.

## What changed

### Auto-import photos page

- **Rename** is available while work is running. A name entered then is saved, and LensLedger applies it once the work has finished. The page does not need to stay open.
- The folder shows the name it is waiting to receive, with **Cancel**. Entering a different name replaces it.
- Saved names are kept when LensLedger is closed, and applied after the next start once nothing is running.
- A name that is already taken is still refused at once.
- A saved name that cannot be applied is shown on the folder with the reason and **Dismiss**, and is recorded in the activity log. A folder that another program has open is tried again for about a minute first.
- A saved name for a folder that no longer exists is dropped and recorded in the activity log.

### What counts as running work

- An automatic scan counts as running from its first step to its last, including between steps. A second automatic scan does not start during that time.
- Indexing faces for appearance search, and publishing after a person is renamed, also hold a folder rename back.

## Verified

- Full test suite: 776 tests, all passing.
- Browser, on a generated test library: the waiting and failed states in light and dark themes and at phone width, and a name saved before start being applied after start.
