## Motivation

When Review People ran out of suggestions, it showed "Checking for more matches…" with no visual activity — no spinner, no progress. The screen looked frozen even though the face learning process was actively running in the background. With 50,000+ faces this can take a noticeable amount of time.

## What changed

### Spinner on the learning screen

The "Checking for more matches" screen now shows a spinning animation (reusing the existing `.saving-spinner` CSS) and clearer text: "Analyzing confirmed faces to find new suggestions. This may take a moment with large libraries."

### Learning results in the header

After learning completes, the header briefly shows what was found (e.g. "Found 42 new suggestions, 3 auto-confirmed — loading…") before the next batch loads.

### Terminal logging for learn

The learn process now logs to the terminal:

```
[People review] Learning from confirmed faces…
[People review] Built 8 profile(s), 42 suggestion(s), 3 auto-confirmed
```

## Files changed

- `src/photo_search.py` — added print logging to `learn_people()`
- `web/js/people-review.js` — spinner + progress text in `autoLearnOnEmpty()`
