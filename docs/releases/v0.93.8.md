The About LensLedger dialog was a plain text dump — no logo, no visual hierarchy,
just a bold title and a bullet list of links. It looked out of place in an app
that otherwise has polished UI throughout.

## What changed

The About dialog has been completely redesigned:

- **Logo front and center** — the LensLedger logo now sits prominently at the top
  of the dialog with a subtle shadow and rounded corners.
- **Hero section** — the app name, tagline ("Your photos, understood."), and a
  version pill are centered beneath the logo with a gentle gradient background.
- **Current library card** — the active library path is displayed in a styled
  card with an uppercase label, replacing the inline `<code>` block.
- **Project link cards** — "Other projects by the developer" are now individual
  hoverable cards with the project name in accent color and a description below,
  instead of a plain `<ul>` bullet list.
- **Close button** — repositioned as a circular pill in the top-right corner with
  a frosted-glass backdrop effect, replacing the old bordered square button.
- **Dark mode** — all new elements use CSS variables and work correctly in both
  light and dark themes.

## Verified

- **Test suite**: 88 tests passed (Python 3.14, Windows).
- **Browser verification**: visually confirmed the dialog in both light and dark
  mode. Logo renders correctly, project cards highlight on hover, version pill
  and library card are properly styled, close button works.
