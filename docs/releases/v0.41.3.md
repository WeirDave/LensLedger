# LensLedger v0.41.3 — Restyle info buttons

## Motivation

The info buttons (small circles with ⓘ) were nearly invisible — the Unicode
circled-i character rendered inconsistently across platforms, appearing off-center
and wonky, and the button itself blended into the background with no border
and a flat secondary color that didn't read as interactive.

## What changed

Restyled every info button in both the viewer and scan-photos pages:

- **Character**: replaced `ⓘ` (Unicode circled information source) with a plain
  `i` letter, which renders consistently across all platforms.
- **Font**: Georgia serif, italic — the classic "information" look.
- **Layout**: `display:inline-grid` with `place-items:center` for reliable
  centering regardless of font metrics.
- **Border**: 1.5px solid in the accent color (gold), making the circle clearly
  visible against any background.
- **Background**: transparent instead of the flat secondary color, so the
  accent-colored ring is the primary visual.
- **Size**: consistent 20x20px across all pages.
- **Hover**: fills with the accent color and swaps the text to the background
  color, giving clear interactive feedback.

### Files changed

- `src/photo_search.py` — replaced `ⓘ` with `i` in all info-button elements
  (8 buttons across the viewer page; the sidebar-toggle button kept its `ⓘ`
  since it is a different component).
- `web/css/viewer.css` — new `.info-button` base styles and hover state;
  simplified `.scope-field .info-button` override.
- `web/css/scan-photos.css` — matching `.info-button` styles for the scan page.

## Verified

- Test suite: 79 tests passed.
- Browser verification: confirmed all 8 info buttons render at 20x20px with
  gold accent border, centered italic serif "i", and transparent background.
  Popover open/close behavior unchanged.
