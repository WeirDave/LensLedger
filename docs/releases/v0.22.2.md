LensLedger now handles a temporary catalog lock safely when you merge duplicate
People names. It waits for brief activity to finish, prevents conflicting work
from starting at the same time, and tells you plainly when you should retry.

## Included

- A 30-second SQLite busy wait for normal LensLedger catalog connections and
  backup operations
- An up-front write reservation for a People merge, so another writer cannot
  interrupt the merge midway
- Protection against a simultaneous People merge or active scan, OCR, or
  meaning-indexing job
- A safe, actionable conflict message that confirms no names were merged
- Immediate cleanup of a catalog connection whose startup encounters an error

## Verified

- Automated coverage confirms a merge reports a safe HTTP conflict while the
  catalog is busy and that the failed connection is released on Windows.
- The full automated Windows test suite passes on Python 3.11 and Python 3.14.
