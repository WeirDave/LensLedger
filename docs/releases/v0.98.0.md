## Settings page TOC and model management

The settings page had two usability issues: the table of contents (TOC) sidebar links didn't scroll to their target sections when clicked, and the Meaning search model section gave no indication of whether a model was already downloaded or how to remove one.

### TOC navigation fix

The TOC links used `scrollIntoView({behavior:'smooth'})` which can fail silently in some browser environments. The scroll handler has been replaced with explicit `window.scrollTo()` using a calculated offset that accounts for the sticky header (80px). Clicking a TOC link now also updates the URL hash via `history.replaceState`, making deep links to specific settings sections bookmarkable and shareable.

The page-load hash navigation was also generalized — previously it only worked for `#meaning-search`, now it scrolls to any valid section hash on load.

### Model download status

Each model in the Meaning search section now shows its download status:

- **Downloaded** — with the actual file size on disk (e.g. "Downloaded · 338 MB")
- **Not downloaded** — indicating the model will be fetched automatically when meaning search is first run with that model selected

This is determined by checking for the cached `.pt` files in the OpenCLIP cache directory (`~/.cache/clip/`).

### Model deletion

A **Delete** button appears next to any downloaded model that is not currently selected. Clicking it removes the cached model file from disk after a confirmation prompt. This lets users reclaim disk space when they've switched to a different model or no longer need meaning search.

The delete endpoint prevents deletion of the currently active model — users must switch to a different model first.

### Informational text

The model section's intro text now explains that the selected model is downloaded automatically on first use and that unused models can be deleted.
