# LensLedger v0.43.22

## Review card text wrapping

The previous fix (v0.43.21) only addressed the "This photo contains ..." button label. The filename, folder description, and confidence percentage on review cards were also affected:

- **Filenames** used `white-space: nowrap` + `text-overflow: ellipsis`, truncating long names like screenshot filenames.
- **Folder descriptions** had the same truncation, hiding useful context about where the photo lives.
- **Confidence percentage** had no `flex-shrink: 0`, so it could be squeezed to zero width when the filename was long.

Now all three wrap properly: filenames and folder text use `word-break: break-word` to wrap to multiple lines when needed, and the confidence percentage uses `flex-shrink: 0` so it always stays visible.

## Verified

- Test suite: 79 tests, all passing.
- Browser verification: confirmed all 8 cards show full filenames, folder paths, and confidence percentages without overflow or truncation.
