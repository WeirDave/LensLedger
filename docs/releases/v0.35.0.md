Every metadata action in LensLedger — tagging, trashing — was previously
limited to one photo at a time. Users who imported a batch of vacation photos
and wanted to tag them all "Hawaii 2026" had to click through each one
individually. This release adds multi-select and batch operations to the
filmstrip.

## Multi-select

- **Ctrl+click** (Cmd+click on macOS) toggles individual photo selection in
  the filmstrip. Selected photos get a blue border and a checkmark badge in
  the top-right corner.
- **Shift+click** selects a contiguous range from the last clicked photo to
  the current one, making it easy to select an entire batch.
- **Plain click** (no modifier) clears any selection and navigates to the
  clicked photo as before.
- **Escape** clears the selection at any time.

## Batch action bar

When one or more photos are selected, a floating bar appears above the
filmstrip with:

- **Count** — "N selected" badge
- **Tag input** — type tags (comma-separated), hit Enter or click "Add tags"
  to apply them to every selected photo
- **Trash selected** — moves all selected photos to the review bin after a
  confirmation prompt
- **Clear** — deselects all

## Backend

Two new API endpoints support the batch operations:

- `POST /api/tag/add-batch` — accepts `{ids: [...], tag: "..."}`, applies
  tags to all specified photos in a single database transaction. Maximum
  500 photos per request.
- `POST /api/review-bin/batch` — accepts `{ids: [...]}`, moves all specified
  photos to the review bin. Maximum 500 photos per request.

Both endpoints reuse the same validation, tag deduplication, and search
index rebuild logic as their single-photo equivalents.

- Test suite: 79 tests, all passing.

  borders and checkmark badges appear on each. Batch-tagged all 3 with
  "Museum Visit", confirmed the tag appeared on each photo's detail view.
  Shift+click to select a range of 5, verified count updates. Escape to
  clear selection, verified bar hides and blue highlights disappear.
