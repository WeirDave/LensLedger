# LensLedger v0.62.1

## Console timestamp format improvement

The console window timestamps were in 24-hour format with no date (`[13:14:08]`). For long-running operations like a first-time library import that could span hours or overnight, the lack of a date made it hard to tell when things happened.

Timestamps now use 12-hour format with the full date:

```
  [2026-08-28 01:14:08 PM] Library: C:\Dropbox\Photos
  [2026-08-28 01:14:08 PM] Database: C:\Dropbox\Photos\.LensLedger\LensLedger-Photos.sqlite3
  [2026-08-28 01:14:08 PM] Auto-import: enabled (every 10 min)
```
