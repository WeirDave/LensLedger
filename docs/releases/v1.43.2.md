# Restore from photo names, built with the latest fixes

## Why this release

- The 1.43.0 and 1.43.1 downloads were built without the changes made in 1.42.2. This release contains all of them and replaces both.

## What changed

- **Restore from photo names** on the people index, added in 1.43.0, is included. It is described in the 1.43.0 notes.
- The changes made in 1.42.2 are included: moving a photo to Trash no longer fails while a library scan is running, and a scan no longer removes a photo, together with its tags and people, when the photo was moved to Trash or its file reappeared during the scan.
- No other change.

## Verified

- Full test suite: all passing.
