LensLedger can now merge duplicate People records without losing the photos,
alternate spellings, or useful review context already attached to either name.

From the People library, choose **Merge people**, select the record to keep,
and choose one or more duplicate names. The retained record stays the primary
name; every merged primary name and alternate name becomes a searchable alias.

When two records are attached to the same photo, LensLedger keeps the most
reliable decision: confirmed first, then suggested, then rejected. An exact
face reference is retained whenever it belongs to that winning decision.
Confirmed JPEGs are rewritten through the normal safety-backup and pixel-check
workflow so the duplicate name is removed from their People Shown metadata.

## Included

- Merge one or many duplicate People records into a chosen primary record
- Retention of merged names and aliases as searchable alternate names
- Safe reconciliation of conflicting per-photo People decisions
- Exact face-reference retention for the winning association
- Metadata backups and pixel verification for affected confirmed JPEGs
- Automatic local profile and suggestion rebuild after a merge
- Closed-but-preserved prior review records for merged duplicate identities

## Verified

- Server regression coverage confirms that a duplicate confirmed decision beats
  a weaker suggestion, aliases are retained, the duplicate record is removed,
  and associated review history remains preserved but non-undoable.
- The full automated Windows test suite passes on Python 3.11 and Python 3.14.
