## Motivation

When tagging faces in the People review page, it's easy to forget that confirmed names are only saved to the database — they aren't written into the actual photo files (IPTC/XMP metadata) until you visit the Publish page. Without a visible reminder, unpublished tags can accumulate silently, and other apps (Lightroom, Google Photos, etc.) won't see the names.

## What changed

A publish reminder banner now appears at the top of the Tag Faces page whenever there are confirmed names that haven't been published to file metadata yet.

The banner shows a summary like "21 people tagged across 210 photos — not yet published to file metadata" with a "Publish now" button that links directly to the Publish page.

### How it works

- The `/api/faces/unidentified` endpoint now includes `unpublished_people` and `unpublished_photos` counts alongside the existing face data.
- The counts come from the `asset_people` table: confirmed entries with no `published_at` timestamp.
- The banner updates on every face grid load and hides automatically when there's nothing to publish.
- Styled with warm amber tones that work in both light and dark themes.

## Verified

- Test suite: 88 tests passed.
- Browser verification: confirmed the banner appears with correct counts on the Tag Faces page in both dark and light themes, and the "Publish now" button links to the Publish page. Banner is hidden when no unpublished tags exist.
