# LensLedger v0.64.2

## Enlarge button on "Also looks like" match thumbnails

### The problem

When you name a face on the Name faces page, LensLedger shows an "Also looks like" group with similar unidentified faces for one-click confirmation. But those thumbnails were only 74px crops with no way to see the full photo. For blurry, dark, or small crops, you couldn't tell whether the match was actually the same person — you had to guess or skip it.

### The fix

Each match thumbnail now has an "Enlarge" button directly below it. Clicking it opens the same lightbox used by the main face grid — full photo with the face highlighted by a bounding box. The backend now returns `asset_id` and bounding box coordinates for similar-face matches so the lightbox can show exactly where the face is in context.

The button sits below the thumbnail rather than overlaid on it, since the thumbnails are small and a corner button would be too hard to click.

## Verified

- Test suite: 80 tests passed.
- Browser verification: named a face, "Also looks like" group appeared with Enlarge button below the thumbnail, clicked it, lightbox opened showing the full photo with "This face" bounding box highlight.
