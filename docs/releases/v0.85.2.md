## Consolidated alphabet bar with action buttons

The People Index page header was simplified from two separate bars (alphabet + heading/buttons) into a single compact bar. The alphabet letters sit on the left, and the action buttons (people count badge, Merge people, Tag faces) sit on the right. The old "People Index" heading and description paragraph were removed to reduce visual clutter.

### Flush bar fix

The gap between the page header and the alphabet bar was caused by the `.people-browser` container's `padding-top: 24px`. Previous attempts used negative margins, which worked inconsistently across viewport sizes. The fix uses `.people-browser:has(.alpha-bar) { padding-top: 0 }` to cleanly remove the padding when the alphabet bar is present.
