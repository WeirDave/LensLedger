## Why this release

Embedded writing was limited to JPEG and HEIC/HEIF. With "Write mode"
(Settings → Metadata publishing) set to "Embedded (modify photo files)",
every PNG, WebP and TIFF photo was listed under "got a sidecar file instead"
with the reason ".png files cannot carry embedded tags". The bundled ExifTool
can write the same metadata into all three formats.

## What changed

### Writing tags ("Write all tags", "Publish all", single-photo writes)

- **PNG (.png), WebP (.webp) and TIFF (.tif, .tiff) are now embedded.**
  Keywords, people, title and description are written into the file itself,
  with the same safeguards as JPEG: a verified safety copy first, a pixel
  comparison afterwards, and a restore from the safety copy if anything
  fails. "Restore last publish" works for these formats too.
- **Where each field goes.** PNG and TIFF receive XMP, IPTC and the EXIF
  description, as JPEG does. WebP has no IPTC block, so its keywords, people,
  title and description are written to XMP and EXIF only. Every category is
  still written.
- GIF and BMP still receive a sidecar file, as neither format can carry this
  metadata.
- "Repair" on the list of photos that could not be written is still offered
  only for JPEG and HEIC/HEIF, since it re-saves the picture as JPEG.

### Reading tags (library scan)

- **Keywords and people stored in PNG, WebP and TIFF files are now read.**
  Previously these formats were not checked for keywords that other programs
  had written. The next scan reads embedded keywords once for every photo in
  the library, including unchanged ones. That scan may take longer than
  usual.
- **Existing keywords are kept.** An embedded write makes the file match
  what the library holds. If a photo's embedded keywords have not been read
  yet, the write now reads them first, so keywords that another program put
  in a PNG, WebP or TIFF file are kept rather than replaced.

### Text

- The "Write mode" hint in Settings, the publishing help text, and the
  format table in the user manual now list PNG, WebP and TIFF as
  publishable.

## Verified

- Full test suite: 239 tests, all passing.
- New test: "Write all tags" in "Embedded" mode on synthetic PNG, lossless
  WebP, uncompressed TIFF and LZW-compressed TIFF files. Each is written with
  no failures and no sidecar. Keywords, people, title and description read
  back from the file, and the pixels are identical.
- New test: a PNG carrying a keyword from another program, whose embedded
  keywords have not been read by a scan. After "Write all tags" the file
  holds both its own keyword and the library's. With the read-first step
  removed, the test fails and the file's own keyword is lost.
- The existing test for files that cannot be embedded now uses a GIF, and
  still reports it by name under "got a sidecar file instead".
- ExifTool writes to all four formats were also checked directly with
  non-ASCII keyword text. The keyword reader returned the written keywords
  and people for each format.
