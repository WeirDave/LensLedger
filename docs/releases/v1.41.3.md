# Tag faces button shows the number of faces to tag

## Why this release

- The **Tag faces** button on the people index displayed the number of suggested matches waiting for review. The page it opens lists unnamed faces, and there are usually many more of those, so the number on the button did not match what appeared after clicking it.

## What changed

### People index

- **Tag faces** now shows the number of unnamed faces, which is the same figure shown at the top of the Tag faces page.
- Faces that were skipped, set aside, marked unknown or ignored, and faces in photos in the review bin, are not counted.
- Suggested matches are still reviewed from **Review suggestions** and from each person's page.

## Verified

- Full test suite: 661 tests, all passing.
- A new test checks that the button count equals the total reported by the Tag faces page, with suggested matches and skipped faces present.
