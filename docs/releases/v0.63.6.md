## Auto-import matches existing named folders and skips duplicates

### Folder matching

The date sorting template generates bare date folders like `2026/2026_08_22`. But users name their folders with descriptions: `2026_08_22 - Beach Day`. Previously, auto-import would create a new bare folder alongside the named one. Now it checks whether an existing folder in the same parent starts with the generated date prefix and uses it if found.

### Duplicate skipping

If a file with the same name and size already exists at the destination, auto-import logs "already exists" and skips it instead of creating a `_1` suffixed copy. This is a lightweight stat-only check — no file hashing.

### Filename collisions

When a file with the same name but different size exists (genuinely different file with the same camera-generated name), the numeric suffix counter still kicks in as before.
