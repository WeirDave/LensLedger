## Why this release

The repository carried two files that no part of LensLedger reads:
`CONVENTIONS.md`, a second copy of the coding-assistant instructions in
`CLAUDE.md` kept for the Aider coding tool, and a roadmap notes file in the
`.claude` folder. A duplicate copy of the instructions can drift from the
original, and the roadmap was not maintained.

## What changed

- Removed `CONVENTIONS.md`. `CLAUDE.md` remains the single set of
  instructions for coding assistants.
- Removed `.claude/stuff we need to work on.txt`.
- No change to the application, its settings, or the photo catalog.

## Verified

- Full test suite: 218 tests, all passing, on Python 3.12.10.
- Nothing in the source, tests, workflows or launch scripts referenced either
  file.
