## What changed

Updating LensLedger keeps the previous installation rather than deleting it, so
a bad release can be rolled back. Nothing ever removed those copies. Each one is
a complete installation — around 40 MB — so they accumulated on disk for as long
as someone kept updating, invisibly.

An update now clears the older ones, keeping the two most recent: enough to step
back from a bad release and then back again.

The clearing is deliberately narrow. It only considers folders named exactly
like this installation's own previous copies, only ones carrying the marker that
identifies a LensLedger installation, and never the installation in use. A
folder someone happens to have left alongside with a similar name is left alone.

## Verified

- Full test suite: 196 tests, all passing, on Python 3.12.10 — up from 192.
- New tests confirm the oldest copies go first and exactly two survive, that a
  similarly named folder without the marker is untouched along with its
  contents, that the installation in use is never removed, and that copies are
  listed newest first.
- Removing the marker check, and separately disabling the clearing, were each
  confirmed to fail the matching test.
