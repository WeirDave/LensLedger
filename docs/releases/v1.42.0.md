# Publish photos page shows a live activity log

## Why this release

- What LensLedger does during a long run, such as **Write all tags**, was visible only in the terminal window it was started from. The Publish photos page now shows the same lines as they are written.

## What changed

### Publish photos page

- A new **Activity log** window sits below the **Write all tags** controls. It looks like a code block with a title bar and a green **Live** indicator, and new lines appear at the bottom as they are written.
- Each line shows the time, the action that wrote it in blue, and the detail. Lines reporting that something could not be done are shown in red, and lines reporting that a run finished are shown in green.
- The window follows the newest line. Scrolling up stops it following, and scrolling back to the bottom resumes.
- **Copy** copies the lines shown. **Clear** empties the window only; the terminal and the log file are not affected.
- The window holds the 500 most recent lines, including lines written before the page was opened. It shows **Not connected** if LensLedger cannot be reached, and catches up on its own once it can.
- The lines contain real photo and folder paths, as the terminal does. The page says so beside the window, as a reminder to remove them before sharing a copy or a screenshot.

### Manual

- Both manuals describe the **Activity log** under **Write all tags**.

## Verified

- Full test suite: all passing, including new tests for the recent-lines buffer and the page.
- Browser: the window checked in light and dark themes and at phone width, against a generated test library.
