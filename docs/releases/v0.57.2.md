## User manual

Added a comprehensive user manual at `docs/user-manual.md`. The app previously had only a brief in-app Quick guide covering shortcuts and formats, plus per-release notes. There was no single reference document covering how to use all of LensLedger's features.

The manual covers:

- Getting started and onboarding
- Library management (adding, switching, relocating, database location)
- All scanning operations (photo locations, OCR, meaning search, face detection)
- Searching and browsing (scopes, sorting, date filtering, filmstrip)
- Viewing and editing photo metadata (subjects, tags, people, events)
- People and faces (naming, reviewing, merging, aliases)
- Photo map
- Auto-ingest pipeline (date sorting, override rules)
- Publishing metadata to files
- Review bin (trash)
- Batch editing
- Database operations (backups, export, import)
- Settings reference
- Keyboard and mouse shortcuts
- Supported file formats
- Advanced configuration (data directory, command-line options, environment variables)
