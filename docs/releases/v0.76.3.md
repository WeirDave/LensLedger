## Motivation

When a person reaches the "Confirm all remaining" threshold (10+ confirmed
with 100% accuracy), both "Confirm all remaining (N)" and "Confirm all"
buttons appeared side by side in the match group header. With all faces
pre-checked, both buttons looked like they did the same thing, causing
confusion about which one to click.

The buttons actually do different things: "Confirm all" confirms only the
visible checked faces and then searches for more iteratively, while "Confirm
all remaining" confirms the visible faces AND sweeps the entire face database
to auto-confirm everything above the suggestion threshold. But when the user
has already built strong trust (70+ confirmed at 100% accuracy), the
iterative option is unnecessary clutter.

## What changed

When "Confirm all remaining" is available, the regular "Confirm all" button
is now hidden. Users see a single clear action. If they want to be iterative
(e.g. uncheck some faces first), "Not these" dismisses the group and the
unchecked faces return to the grid.
