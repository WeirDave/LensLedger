The faces review page has a "Who is this?" name picker on each face card that
lets you type a name and pick from existing people. This picker is populated
by `/api/faces/unidentified`, which returns a `people_options` list.

Two other endpoints — the photo viewer and the people-review page — correctly
built that list with:

```sql
SELECT name FROM people UNION SELECT alias FROM person_aliases ORDER BY 1 COLLATE NOCASE
```

But the faces-review endpoint only queried:

```sql
SELECT name FROM people ORDER BY name COLLATE NOCASE
```

This meant that if you gave someone an alternate name (e.g. "Bobby" for
"Robert Smith"), typing "Bobby" in the faces review picker would show no
match — the alias simply wasn't in the list.

## What changed

Updated the query in the `/api/faces/unidentified` handler to include
`person_aliases`, matching the other two endpoints.
