GitHub Actions began deprecating Node.js 20 runners. The Release workflow
used `softprops/action-gh-release@v2`, which targets Node.js 20 and produced
a deprecation warning on every release.

Updated to `softprops/action-gh-release@v3`, which targets Node.js 22+
and eliminates the warning.

## Verified

- Full test suite: 101 tests passed.
