# LensLedger v0.65.3 — Terminal logging for Name Faces

## Motivation

The Name Faces page (`/faces-review`) writes metadata tags when you name a face, but nothing appeared in the terminal. Only Review People had logging.

## What changed

Added a `[Name faces] Named "Person Name" in filename.jpg` log entry to the `name_face` handler. This covers both the initial naming and the "Also looks like" match confirmations, since both call the same `/api/faces/name` endpoint.

## Files changed

- `src/photo_search.py` — added print logging to `name_face()`

## Verified

- **Test suite**: 80 tests, all passing.
