## Motivation

The group manager cards previously had no avatar thumbnails, making it hard to identify people at a glance. An earlier attempt used client-side CSS cropping via inline styles (`object-position` + `transform: scale`), but that approach was blocked by the Content Security Policy (`style-src 'self'`).

## What changed

Switched to server-side face cropping using the existing `/media-face?face_id=X` endpoint, which uses Pillow to crop and pad around the face bounding box, returning a 360x360 max JPEG thumbnail.

- Updated the `/api/people/all-with-groups` endpoint to return `face_id` (the `face_embeddings.id`) instead of raw `face_box` coordinates.
- Updated `group-manager.js` to use `/media-face?face_id=X` as the avatar `src` when a face ID is available, falling back to `/media?id=X` for the full photo, or a person emoji when no photo exists.
- Re-added `.gm-person-avatar` CSS styles — 40px circular thumbnails with `object-fit: cover`.
- Removed the inline-style cropping code that CSP would have blocked.

## Verified

- Test suite: 88 tests passed.
- Visual verification in browser: avatars display correctly with face-cropped thumbnails in both light and dark themes.
- Group selection border highlight (4px accent) works correctly alongside avatars.
- Fallback to person emoji icon works for people without photos.
