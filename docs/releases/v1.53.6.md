# Face detection stays on the graphics card after package updates

## Why this release

- The weekly package update could install the processor build of the face-detection runtime over the graphics-card build. InsightFace lists the processor build as a requirement, so updating InsightFace brought it back.
- Face detection then ran on the processor, far more slowly.
- The status line under **Face detection** said to use the **Use my graphics card** button, but the button was hidden.

## What changed

### Package updates

- Where the graphics-card runtime is installed, the weekly update upgrades InsightFace without installing its requirements, so the processor runtime is no longer added.

### Face detection

- On an affected computer, **Use my graphics card** appears again under **Face detection** on **Scan your photos**. Pressing it restarts LensLedger and reinstalls the graphics-card runtime. Updating LensLedger alone does not switch the runtime back.
- The button appears only while face detection is running on the processor and the computer's NVIDIA card and driver can run it.
- The switch removes both runtimes before installing the graphics-card one. If that installation fails, the processor runtime is put back.
- Faces already found are not changed.

## Verified

- Full test suite: 747 tests, all passing.
