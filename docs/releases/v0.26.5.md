Docs-only follow-up to 0.26.4: the README now says out loud what the app
itself started telling people at launch and in the update panel.

## What changed

- **Quick start, step 4** now explicitly warns to run `Install
  LensLedger.cmd`, not `Start LensLedger.cmd` — the self-update mechanism
  depends entirely on that first click.
- **Updates and rollback** gained a short section spelling out the two
  ways to end up unable to self-update — an extracted ZIP run directly,
  or a `git clone` checkout — and the correct fix for each, matching the
  messages LensLedger itself now shows in both places.
- **Run from source** now states plainly that a checkout updates via
  `git pull`, and clarifies the restart-vs-refresh split: backend (`.py`)
  changes need the process restarted, front-end (`.js`/`.css`) changes
  are read from disk on every request and just need a browser refresh.

No code changed in this release — README.md only.

## Verified

- Full automated suite (64 tests) green (unchanged from 0.26.4; this is a
  documentation-only release).
