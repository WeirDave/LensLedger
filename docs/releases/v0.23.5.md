The first-run setup wizard now tells you where your data actually lives,
and gets text recognition started before you even open your library.

## No more mystery about where things end up

Setting up a new library never explained where LensLedger's index,
backups, and everything else it creates actually go. The intro screen now
says so plainly, in the same breath as reassuring you your photos
themselves never move.

## Text recognition, right up front

Previously, OCR (reading visible text in photos — signs, screenshots,
receipts) was only discoverable later, tucked into the Library health
panel. The setup wizard's completion screen now offers a one-click "Scan
for text now" the moment your initial scan finishes, using the same
background job Library health already drives.

## Verified

- Full automated suite (44 tests, including new coverage for the
  onboarding page's data-location text and OCR button).
- Manually verified live against a throwaway empty library: the
  data-location disclosure renders with the real path, a full scan
  completes, and clicking "Scan for text now" actually starts OCR and
  updates the message.
