LensLedger now creates a verified, full catalog backup automatically before it
merges duplicate People records. This gives every merge a clear recovery point
without requiring you to remember a separate backup step first.

The backup uses SQLite's online backup API and is retained only after a
successful integrity check. It is stored with your other LensLedger catalog
backups, separately from the application and photo files.

## Included

- Automatic verified catalog backup immediately before every People merge
- Merge result reports the backup location along with the affected-photo count
- Shared backup implementation for both the manual Library Health backup and
  the merge safeguard

## Verified

- Server coverage confirms a verified catalog backup exists when a merge
  completes.
- The full automated Windows test suite passes on Python 3.11 and Python 3.14.
