## Motivation

The scan error modal had a "Report on GitHub" link that appeared alongside
every error list. But most scan errors are file-related quirks (images the OCR
engine can't decode, timeout on large files) — not LensLedger bugs. Having
a bug-report link right next to explained-and-expected errors sent the wrong
signal: it looked like something was broken when really the photo just used
an encoding Windows can't read.

Meanwhile, there was no general-purpose way for users to find support or
report actual bugs from within the app.

## What changed

1. **Removed the "Report on GitHub" link from the error modal.** The modal
   still shows each error with its plain-English explanation and the "Copy all
   to clipboard" button for troubleshooting.

2. **Added "Help & support" to the main menu on all pages.** The link opens
   the LensLedger GitHub issues page in a new tab. It appears on:
   - The main photo library page (hamburger menu)
   - The Review people page (hamburger menu)
   - The Name faces page (hamburger menu)

## Verified

- Test suite: 79 tests passed.
- Confirmed the three menu HTML blocks in photo_search.py each contain the
  new help link.
- Confirmed the error modal JS no longer creates a report link element.
