# LensLedger v0.44.0

## Consistent photo interactions and trash from review pages

Photo interactions were inconsistent across the app: people review had an enlarge button but faces review didn't, and double-click did different things on different pages (enlarge in reviews, 3x zoom in the viewer). Meanwhile, there was no way to trash a photo while reviewing faces or people without navigating back to the main library.

### What changed

**Double-click reveals the file on disk everywhere.** Double-clicking a photo on any page now opens Explorer (Windows), Finder (macOS), or the system file manager (Linux) with the file selected. This replaces the previous inconsistent behavior where double-click enlarged photos in reviews and toggled 3x zoom in the viewer.

**Triple-click for 3x zoom in the viewer.** The viewer's in-place zoom toggle moved from double-click to triple-click, keeping it accessible without conflicting with the new reveal behavior.

**Enlarge button on faces review.** The same single-click "⛶ Enlarge" button from people review now appears on every face card in faces review, positioned top-right on the face photo. Opens the lightbox to see the full photo for context.

**Trash button on both review pages.** A 🗑 trash button appears on every photo card in people review and faces review. Clicking it prompts for confirmation, moves the photo to Trash, removes the card from the grid, and shows an undo toast for 12 seconds.

### Backend

Added `/api/reveal-file` endpoint that accepts an asset ID and opens the file's location in the system file manager using platform-appropriate commands (`explorer /select,` on Windows, `open -R` on macOS, `xdg-open` on Linux).

## Verified

- Test suite: 79 tests passed.
- Browser verification: faces review and people review pages load with correct button counts (expand + trash on every card), no console errors. Main viewer loads cleanly with updated double-click/triple-click handlers.
