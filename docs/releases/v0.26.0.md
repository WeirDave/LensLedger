Direct user feedback, fixed the same day: a real face-naming screen, real
progress bars, and a round of dead-end navigation fixes.

## The missing screen: "Name faces"

The single biggest complaint: "where do we go to find unidentified faces so
we can make more matches?" The honest answer, before today, was nowhere.
Face detection filled a `face_embeddings` table with unlabeled faces, but
there was no page to browse them — the only way to teach LensLedger a face
was to already know who was in a photo and type their name onto it in the
main viewer, and on any group photo that typed name silently never trained
the matcher (no way to say *which* face in the photo it belonged to).

`/faces-review` closes that gap: a grid of cropped face thumbnails, newest
detected first, each with an inline name field. Typing a name and pressing
Enter links it straight to that one face (`asset_people.face_id`), which
`face_learning.build_profile()` already knew how to use for exactly this
case — it just never had a source of face-linked confirmations to draw
from. A "Not a person" button handles pets, statues, and reflections; those
faces are excluded from both the review queue and from ever being scored
against a person's profile.

## Real progress, not just a spinner

OCR, meaning search, and face detection status was always polling
done/total counts from the server — the UI just printed them as two
disconnected numbers next to a spinner. Scan your photos now shows an
actual percentage bar and an estimated time remaining, computed from
elapsed time and the observed rate. "Run all scans" shows which step
it's on out of how many apply to this install (2 or 4, depending on
whether meaning search and face detection are set up).

## "All scans complete" was lying by omission

`_run_scan_all_job` reported the exact same "All scans complete." message
whether it ran all four steps or silently skipped meaning search and face
detection because they weren't installed yet. It now says which steps ran
and which were skipped, e.g. *"Ran: photo locations, OCR. Skipped (not set
up yet): meaning search, face detection — set up below."*

## Dead-end navigation

Several places pointed users at "Library health" — a panel that was
replaced by the "Scan your photos" page back in 0.24.2, but the name never
got updated in onboarding text, an error message, and the README. Fixed
those, and — since Scan your photos and People review had no way to reach
each other except through the main viewer's hamburger menu — added a small
header nav (Scan photos · Review people · Name faces · Photo map) to every
non-viewer page.

## Also

- The per-person "Edit names" button was renamed to "Edit name" — it only
  ever edits one person, and the plural read like a bulk action across the
  whole grid.
- The meaning-search and face-detection install buttons now state their
  download size up front and explain why they're not bundled into the base
  install (large downloads most people don't need, and the face model's
  license doesn't permit redistribution), and show an animated progress
  bar instead of a bare spinner while installing.
