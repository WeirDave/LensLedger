Added security policy and GitHub issue templates, adapted from WaxFrame Professional.

## What changed

**Security policy** (`SECURITY.md`): documents how to privately report
vulnerabilities via GitHub's built-in advisory flow, lists supported
versions, and describes LensLedger's threat surface (local-first
desktop app, path traversal and ExifTool injection are the main
concerns, plus irreversible trash/delete operations).

**Issue templates** (`.github/ISSUE_TEMPLATE/`): a structured bug-report
form (what happened, steps to reproduce, environment) and a config that
disables blank issues and links to private vulnerability reporting.
Both adapted from the WaxFrame Professional equivalents with
LensLedger-specific content.

## Verified

- Test suite: 79 tests, all passing.
- No code changes — documentation and GitHub config only.
