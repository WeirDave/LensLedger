The main viewer previously displayed photos at fit-to-container size with
no way to inspect fine detail. Users couldn't verify OCR text against the
actual photo, confirm a face suggestion by zooming in, or check image
sharpness before publishing metadata. The photo was always scaled to fit
the stage area and that was it.

This release adds full zoom and pan controls to the viewer stage:

- **Scroll-wheel zoom** on the photo area scales from 100% up to 2000%,
  with each scroll step applying a 15% multiplicative factor. Zooming out
  below 100% snaps back to fit-to-container.

- **Click-and-drag pan** lets users move around the photo when zoomed in.
  The pan is clamped so the image edges cannot be dragged past the stage
  boundaries. The cursor changes to a grab hand when zoomed, and a
  grabbing hand while actively dragging.

- **Double-click** zooms to 300% for quick detail inspection; double-click
  again resets to fit. This gives a fast two-click workflow for checking
  a specific area of a photo.

- **Zoom indicator** appears in the bottom-left corner whenever the photo
  is zoomed past 100%, showing the current zoom percentage and a
  "Reset zoom" button.

- **Automatic reset** when navigating to a different photo via the
  filmstrip, arrow keys, or prev/next buttons — the new photo always
  starts at fit-to-container.

- **Face bounding box** overlay (shown when viewing a specific person's
  photos) repositions correctly during zoom and pan, staying anchored
  to the detected face region in the image.

## Implementation

The zoom is implemented as a CSS `transform: scale() translate()` on the
image element itself, keeping the existing `object-fit: contain` layout
intact at 1x. Pan coordinates are tracked in image-local space and
clamped against the visible stage area. The face box overlay uses a
shared `repositionFaceBox()` function called after every zoom/pan update
and on window resize.

Zoom state (`zoomScale`, `panX`, `panY`) is module-level and reset in
`selectAsset()` before loading a new photo.

## Verified

- Test suite: 79 tests, all passing.
- Browser testing: scroll-wheel zoom (incremental and rapid), click-drag
  pan at various zoom levels, double-click zoom in and reset, Reset zoom
  button, photo navigation resetting zoom, and zoom controls visibility
  toggling — all verified in the live app against a 50,909-photo library.
