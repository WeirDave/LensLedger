# Version badge on the Photo map page

## Why this release

- The Photo map page was the only page without the version badge in its top bar, so the badge, and the update check that opens from it, were missing there.

## What changed

### Photo map

- The top bar now shows the version badge as its right-most item, after the location count.
- Double-clicking the badge opens the **LensLedger updates** panel on the home page and starts a check for a new release. While a newer release is available the badge shows a green dot and outline, and a single click opens the panel.
- The badge stays visible in narrow windows, where the location count is hidden.

## Verified

- Full test suite: 726 tests, all passing.
- Browser check of the Photo map top bar in the dark theme and the light theme, at desktop width and at a 375 px wide window.
