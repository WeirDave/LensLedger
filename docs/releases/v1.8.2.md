## Why this release

Restarting LensLedger from the "Restart now" button in the "Server is running
… on disk" banner, or by installing an update, opens a new LensLedger window
and is meant to close the old one. The old window was closed by force-stopping
it, which ends it with an error exit code. Windows Terminal keeps a tab open
after an error exit, so on systems where Windows Terminal hosts console
windows (the Windows 11 default) the old tab stayed behind, showing a
"process exited" message.

## What changed

- When the server stops in order to restart, it now exits with a dedicated
  exit code (75).
- "Start LensLedger.cmd" recognises that code and closes its own window
  cleanly, without the "LensLedger has closed normally." message and the
  "Press any key" pause. Windows Terminal then closes the old tab.
- Stopping LensLedger with Ctrl+C, or after an error, behaves as before: the
  window stays open with its closing message.
- The existing forced close is still there as a fallback, for launch windows
  started by older copies of "Start LensLedger.cmd".

## Verified

- Full test suite: 210 tests, all passing, on Python 3.12.10.
- Checked the launcher logic in a separate script: exit code 75 closes the
  window with exit code 0, and a normal exit still reaches the closing
  message.
