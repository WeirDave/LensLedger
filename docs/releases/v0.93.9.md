## What changed

The scan error dialogs (OCR errors, face detection errors, etc.) were functional but visually rough — plain text dumped together with tiny cramped buttons and no visual hierarchy. This redesign gives them a polished, professional layout.

## Error dialog improvements

**File path** — displayed as a bold header line in the accent color. Plain selectable text (no longer styled as a non-functional link). Click-and-drag to select the full path if needed.

**Toolbar buttons** — "Copy filename" and "Open folder" now sit in their own row with proper padding (5px 10px), rounded corners, and 600 font weight. "Copy filename" copies just the filename (e.g. `IMG_6319.JPG`) instead of the full path, so you can paste it into Explorer/Finder's search bar after clicking "Open folder" to navigate to the containing directory.

**Error details** — the raw error message (e.g. the full AggregateException stack) is now rendered in a monospace code box with a subtle background and border, making it visually distinct from the human-readable content. The box scrolls horizontally for long lines and caps at 120px height with vertical scrolling for very long messages.

**Hint callout** — the human-friendly explanation of what the error means now has a subtle accent-tinted background with rounded corners, clearly separating it from the raw error text above.

**Overall spacing** — increased gap between error rows (10px), better internal padding (12px 14px), and a border on each row card for visual definition.

## Verified

- Test suite: 88 tests passed.
- Browser verification: confirmed the redesigned error modal in dark theme — file paths render as selectable text, buttons have proper padding and spacing, error messages appear in monospace code boxes, and hints display as styled callouts.
