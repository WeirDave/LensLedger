## Consistent layout across all pages

The People Review and Name Faces pages had their header and content centered with `max-width` and `margin:auto`, while the main viewer page used edge-to-edge layout. This meant the hamburger menu, logo, version badge, and theme toggle shifted position when navigating between pages — forcing users to hunt for controls that should always be in the same spot.

### What changed

- Removed `max-width:1800px; margin:auto` centering from the topbar on People Review and Name Faces, so the header elements sit in the same position as the main viewer.
- Removed `max-width` centering from the main content area on both sub-pages.
- Removed the matching centering from the People Review action bar.
- Changed the People Review photo grid from a fixed 4-column layout to `auto-fill` with a 280px minimum, so wider screens naturally fit 5-6 review cards per row instead of capping at 4.
- Removed the 1250px breakpoint that dropped to 2 columns — the auto-fill grid handles responsive column counts natively.
- Added "Home" link to the main viewer's navigation menu, matching the sub-pages where it already existed.
