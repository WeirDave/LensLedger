The photo map stops sending you away from the app, and a location cluster
is no longer stuck showing just one photo.

## GPS clicks stay in LensLedger

A photo's embedded GPS coordinates used to open a raw, unstyled
openstreetmap.org page — a dead end that looked nothing like the rest of
the app. Clicking it now opens LensLedger's own map instead, deep-linked
and centered on that exact photo's location.

## See every photo from a place, not just one

The map's location details panel showed a single representative photo per
cluster with no way to see the rest. A new "View all photos here" action
opens the full filmstrip filtered to that location — the same grouping the
map already uses for its markers, now usable from the search view too.

## Verified

- Full automated suite (47 tests, including new coverage for the location
  filter).
- Manually verified live against a throwaway two-location test library:
  deep-linking from a photo's GPS coordinate correctly centers the map and
  opens the right cluster, and "View all photos here" correctly filters to
  just that location's photo.
