## Motivation

The sidebar section previously labeled "Information already in this photo" was wordy and didn't match the terminology used elsewhere. The product calls this data "capture details" — the EXIF, IPTC, and XMP metadata read directly from the file. Renaming brings the label in line with how users talk about it.

Separately, the golden selection border on the active filmstrip thumbnail was 4px, which felt thin at a glance. Bumping it to 5px makes it easier to spot which photo is selected.

## What changed

- Renamed the collapsible sidebar section from "Information already in this photo" to "Capture details" in the HTML template (`src/photo_search.py`).
- Updated the quick guide text in `web/js/viewer.js` to reference "Capture details" instead of the old label.
- Increased the `.thumb` base border width from `4px` to `5px` in `web/css/viewer.css`, making the active selection ring thicker in both light and dark modes.

## Verified

- **Test suite:** 79 tests passed (Python, Windows).
- **Browser verification:** Confirmed "CAPTURE DETAILS" label appears in the sidebar. Confirmed the thicker filmstrip selection border is visible in both dark and light modes.
