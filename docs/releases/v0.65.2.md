# LensLedger v0.65.2 — Real-time terminal logging for batch review

## Motivation

When submitting a large batch (e.g. 100 photos) in Review People, the UI showed "saving tags" but the terminal stayed silent until all metadata publishing finished. The log entries were printed in a batch after the entire operation completed, giving no indication of progress.

## What changed

Moved the `[Name faces]` log printing inside the per-photo publishing loop so each entry prints immediately after its file's metadata is written by exiftool. The filename lookup query was also moved earlier (before the publishing loop) so filenames are available during iteration.

## Files changed

- `src/photo_search.py` — restructured `people_review_batch_decision` to interleave logging with metadata publishing
