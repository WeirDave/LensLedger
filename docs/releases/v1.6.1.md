## What changed

In Settings, under "Metadata publishing", the line explaining
**"Auto-classify photos after meaning search"** sat flush against the left
edge instead of lining up beneath the switch it describes.

The indentation was written directly onto the element rather than in a
stylesheet. LensLedger's pages carry a security policy that forbids styling
applied that way — deliberately, so that nothing injected into a page can
restyle it — so the browser discarded it and the line fell back to the margin.
The styling now lives in the stylesheet where the policy allows it.

## Verified

- Full test suite: 178 tests, all passing, on Python 3.12.10.
- A new test fails if any page is served with styling written onto an element,
  and a second fails if the security policy is ever loosened to allow it, which
  would make the first meaningless.
- Checked in a browser in both light and dark themes: the line now sits under
  the switch.
