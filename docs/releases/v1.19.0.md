## Why this release

These changes came from using LensLedger the way a new owner would: point it
at a library, browse, and try to find the best shots again later.

- **There was no way to mark a good photo.** Subjects, tags and people
  describe what is *in* a photo, but nothing recorded which ones were worth
  keeping. Culling a shoot or finding last summer's best frames meant
  scrolling the whole filmstrip again.
- **The keyboard shortcuts were invisible.** Arrow keys worked, but nothing
  in the app said so, and the manual was the only place to learn them.
- **On macOS and Linux, text recognition failed on every photo, every five
  minutes.** OCR uses the built-in Windows engine. Starting it by hand was
  already refused off Windows, but folder watching and "Run all scans" ran it
  anyway: every photo got an error, the Scan page showed one error per photo,
  and because a failed photo is retried, the next automatic check did it all
  again.

## What changed

**Star ratings**

Under the photo's file name there is now a row of five stars. Click one, or
press **1**–**5**, to rate the photo. Press **0**, or the same number again,
to clear it. With several photos selected (Ctrl/⌘+click or Shift+click), the
number keys rate all of them, and the batch bar has a **Rate selected…** menu
that does the same. Rated photos show their stars in the corner of their
filmstrip thumbnail.

Ratings are stored in LensLedger's catalog, alongside subjects and tags.
They follow a photo that is renamed or moved, and they are not written into
the photo files.

**Rating filter**

A **Rating** menu beside Sort shows only photos with at least 1–5 stars, or
five stars only. It combines with search, the date filter and a person's
photos, and the header says what is being shown, for example "Newest photos
rated ★★★★+ • 1–12 of 12". It does not apply to Meaning search, which ranks
photos by its own score.

**Keyboard shortcuts**

Press **?** on the main page, or select the "Keys: 1–5 rate · 0 clears · ?"
hint under the stars, to see every keyboard and mouse shortcut.

**Text recognition off Windows**

On macOS and Linux the OCR section of Scan your photos now says text
recognition is Windows only, instead of showing counters and a Start button
that can only fail. "Run all scans" and folder watching skip the step, and
the startup summary no longer counts photos as waiting for it. Opening a
library on this version clears the "powershell.exe" errors the earlier
behaviour left on every photo. Nothing changes on Windows.

## Database

Schema version 23 adds an `asset_ratings` table keyed by the photo's path,
like subjects and hidden tags. It is created automatically on first start;
older versions ignore it.

## Fixed during testing

- The stars first rendered at 12px: the sidebar's general button rule set a
  smaller font size and outranked the new style. The star and hint styles are
  now scoped to their own elements.
- Clicking the star that matched the current rating cleared it, but the stars
  stayed lit while the pointer rested on them, so it looked as if nothing had
  happened. The hover preview is now reset after every rating change.

## Verified

- Full test suite on Linux: 311 tests, 305 passing or skipped. The 6 that
  fail fail identically on `main` (v1.18.0) in the same environment: five run
  the bundled Windows `ExifTool.exe`, and one is a meaning-search ranking
  test that depends on the host's file-listing order. This release touches
  neither. The Windows CI run is the authority for those.
- New tests: rating, re-rating and clearing one and several photos; invalid
  ratings refused; the rating carried on filmstrip pages and the photo
  detail; the filter with sort, search and on the full page; a rating
  following a renamed photo; "Run all scans" skipping OCR where it cannot
  run; OCR counted as nothing pending off Windows; and the upgrade clearing
  the old errors.
- Checked in Chromium against a generated 60-photo test library (synthetic
  images, invented folder names): rating with keys and clicks, toggling a
  rating off, batch rating two selected photos, the filmstrip badges, the
  Rating filter and its header text, typing digits in the search box not
  rating anything, the shortcuts list in light and dark themes, the phone
  layout, and the Scan your photos page and "Run all scans" on Linux.
