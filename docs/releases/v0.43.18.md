# LensLedger v0.43.18

## People review batch publish fix

When a people review batch included photos with non-publishable file types (PNG screenshots, for example), the entire batch would fail with "Publishing is not supported for this file type" and no decisions were saved — not even for the JPEG photos in the same batch that could have been published successfully.

The root cause was `_publish_people_metadata` raising a `ValueError` for any file whose extension wasn't in `PUBLISHABLE_EXTENSIONS` (.jpg, .jpeg, .heic, .heif). Because the batch loop wrapped all decisions in a single try/except, one unsupported file would roll back every decision in the batch.

Now `_publish_people_metadata` returns `None` for non-publishable files instead of raising. The batch loop filters out `None` results, so review decisions (confirmed, rejected, corrected) are recorded in the database for all photos, and metadata is written only to the files that support it.

## Label truncation fix

The "This photo contains [person name]" button on people review cards had no text overflow handling. With longer person names or narrower cards (e.g. at smaller viewport widths), the text would overflow the button boundary and get visually cut off. Added `white-space: nowrap`, `overflow: hidden`, and `text-overflow: ellipsis` to `.toggle-wrong` so long labels truncate cleanly.
