Morning-after feedback, fixed the same day: scans now chain together, two
real UX bugs are gone, and the app dropped the blue theme.

## Run all scans

"Scan your photos" gained a single "Run all scans" button that runs photo
locations, OCR, meaning search, and face detection back to back — skipping
any optional scan that hasn't been set up yet — instead of requiring each
one to be started by hand once the last one finishes. It shows which step
is currently running and can be stopped after the current step at any
time.

Verified live against the real library: all four steps ran in sequence —
50,909 files re-checked, remaining OCR and meaning-search backlog cleared,
and 7 new faces found — with zero errors.

## Two real bugs, not cosmetic ones

- **The "Mapped photos" and "People to review" links did nothing.** A
  local variable named `location` was shadowing the browser's own
  `window.location` inside the page's refresh loop, so clicking either
  metric quietly set a property on the wrong object. Renamed the
  variable; both links now navigate correctly.
- **A stale library path could silently replace the real library.** If
  the last-opened library folder no longer existed (a deleted temp
  folder, an unplugged drive), LensLedger fell back straight to the OS
  Pictures folder — even when another known-good library was still on
  record — with no indication anything had changed. `load_library_state`
  now tries every other recently-used library first.

## No more blue

Replaced the app's blue accent color with a warm amber across every page
— the map, the viewer, People review, onboarding, and Scan your photos —
at the user's request.
