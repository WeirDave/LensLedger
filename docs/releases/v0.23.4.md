A small, purely internal cleanup: `static/` is now `web/`.

## Project layout, finished

Python modules moved into `src/` in the last release. This one finishes the
job by renaming `static/` to `web/`, so the top level of the project reads
as: `src/` for code, `web/` for what the browser loads, `assets/` for
images, `tools/` for bundled utilities, `tests/` for the automated suite,
and the two `.cmd` launchers at the root where you'd expect to find them.

This doesn't change how LensLedger looks, runs, or self-updates — it's
strictly a naming and organization change, verified with a full test run, a
live browser check, and a simulated release build launched standalone from
a scratch directory.
