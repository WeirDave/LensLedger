## What changed

Clicking "Check for updates" in the hamburger menu navigated to `/?panel=update`, but the viewer page JavaScript never read that URL parameter on load — so the update panel never actually opened. The user landed on the main photo viewer with no visible result.

## The fix

Added a one-liner at the end of `web/js/viewer.js` that reads the `panel` query parameter from the URL on page load and calls `openMenuPanel()` with it. This covers both `?panel=update` and `?panel=guide` (the Quick Guide), which use the same navigation pattern from every page's menu.
