## Motivation

The "Current library" path shown at the bottom of the hamburger menu was display-only text. Clicking it did nothing, even though the most natural action would be to navigate to the library management area in Settings.

## What changed

The library path in the menu footer is now a clickable link that navigates to `/settings#libraries` — the Photo libraries section of the Settings page. The `<span>` was replaced with an `<a>` tag, and the CSS was updated across all 10 page stylesheets to remove the default link underline and add a hover color change using the accent color.

## Verified

- Test suite: 88 tests passed.
- Browser verification: opened the hamburger menu, confirmed the library path appears as a clickable link, clicked it, and verified it navigated to the Settings page with the Photo libraries section visible.
