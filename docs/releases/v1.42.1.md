# People to review count and link match the review page

## Why this release

- The **People to review** figure on the **Scan your photos** overview counted suggested photos, not people, and opened the Tag faces page, which lists unnamed faces. The number shown and the page that opened did not correspond.

## What changed

### Scan your photos overview

- **People to review** shows the number of people who have suggested matches waiting. Clicking it opens **Review suggestions**, where those matches are confirmed or rejected.
- People set aside for now, and suggested matches in photos in the review bin, are not counted. This is the same figure the review page uses for people remaining.
- **Unidentified faces** no longer includes skipped faces, so it equals the total shown on the Tag faces page. Clicking it still opens the Tag faces page.

## Verified

- Full test suite: 667 tests, all passing.
- A new test checks that three suggested matches belonging to two people count as 2.
