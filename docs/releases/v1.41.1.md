# Filters panel has Apply and Clear buttons

## Why this release

- The Filters panel had no button to apply what was entered. Typing in a date, camera or folder field, or choosing from the people list, only took effect after pressing Enter or the Search button next to the search box, which was not apparent from the panel.

## What changed

### Filters panel

- **Apply filters** is now at the bottom right of the panel and applies everything entered in it together with the current search.
- **Clear filters** appears next to it while any filter is active. It removes every filter (date, rating, taken from and until, people, type, shape, location, camera and folder) and keeps the search text, scope and sort order.
- **Type**, **Shape** and **Location** now apply as soon as a choice is made. The other fields (taken from and until, people, camera, folder) wait for **Apply filters** or Enter, so several can be set before the results change.

## Verified

- Full test suite: 658 tests, all passing.
- The existing filter test now also checks the two buttons and that Clear filters is absent when nothing is active.
- Browser check of the Filters panel in the light and dark themes, including choosing a shape and clearing filters, using a generated library.
