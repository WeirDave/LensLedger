## Scan after import, UI fixes, cleaner console

### Auto-scan after import

When auto-import finishes importing new photos, it now triggers the folder watcher to run a library scan 5 seconds later. Previously, new imports would sit unscanned until the next scheduled folder watcher cycle (up to 30 minutes). Now the flow is: import fires at 5 seconds after startup, imports new photos, then triggers a scan at ~10 seconds — the user sees their new photos indexed almost immediately.

### "Run all scans" button stuck on "Starting scan..."

The button text was set to "Starting scan..." when clicked, but the refresh function only toggled `disabled` — it never reset `textContent` back. Fixed by resetting the button text in the refresh cycle whenever the scan is not running.

### Console logging for manual scans

"Run all scans" now logs `Run all scans: started (manual)` and `Run all scans: complete` to the console, making it clear in the log whether a scan was user-initiated or automatic.

### Overview stat tooltips

The overview metrics on the Scan page (Library files, Mapped photos, People to review, Faces to name, OCR complete, Meaning indexed, Review Bin) now have `title` tooltips explaining what each number means in plain English.

### Face detection console noise

The InsightFace/ONNX runtime prints `Applied providers`, `model ignore`, `find model`, and `set det-size` lines to stdout during model loading. These are now suppressed by redirecting stdout/stderr to devnull during initialization, the same pattern used for scan and OCR quiet modes.

### Renamed "Ingested" to "Imported"

The stats key, status page label, and "Run now" toast all said "Ingested." Changed to "Imported" everywhere.
