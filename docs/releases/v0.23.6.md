Meaning search finally explains itself, and sets itself up with one click.

## What meaning search actually is

The Library health panel's "Meaning search" card used to show the raw
error a missing Python package throws — "Install requirements-semantic.txt
first" — with no explanation of what the feature even does. It now says
plainly: search your photos by what they show, not just their tags — try
"a birthday cake" or "someone holding a dog" — using an image-understanding
model that runs entirely on this computer.

## One click to set it up

Instead of a README command to run manually, there's now a "Set up meaning
search" button right in the panel. It installs the required software as a
background job — after telling you honestly what that involves (roughly
1-2 GB, several minutes, nothing ever uploaded) — and the panel updates
live as it installs. Once it's done, the existing "Build / resume meaning
index" control appears to actually index your photos.
