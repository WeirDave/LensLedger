# LensLedger v0.43.11 — Clean up startup messages and fix restart flag

## Context

The console showed two near-identical messages on startup: "Starting
LensLedger..." from the .cmd script and "Loading LensLedger..." from
Python. These are the same thing from the user's perspective.

Additionally, the `--restarted` flag introduced in v0.43.9 was appended
directly to the file path string (`cmd += " --restarted"`), which meant
`subprocess.list2cmdline` quoted the entire thing as one argument.
On paths with spaces (like this project's Dropbox path) cmd.exe couldn't
find the file. This likely caused the restart failure the user saw.

## What changed

1. Removed the early `print()` at the top of `photo_search.py` (the
   pre-import "Loading LensLedger..." message). The .cmd echo "Starting
   LensLedger..." is sufficient.

2. Fixed `--restarted` passing in `launch_lensledger`: changed from
   concatenating to the path string to appending as a separate list
   element, so subprocess produces the correct command line:
   `cmd.exe /c "C:\path with spaces\Start LensLedger.cmd" --restarted`

3. Moved the browser-tab close reminder into the main startup banner
   (inside the `=====` box), shown only when `args.restarted` is set.
