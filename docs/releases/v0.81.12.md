## What changed

Previously, each scanning mechanism (library scan, OCR, meaning search, face detection) only logged "started" and "complete" messages to the terminal. While a scan was running — potentially for minutes or hours on a large library — the terminal was silent, giving no indication of what was happening.

Now each scanner logs periodic progress to the terminal via `console_log()`:

- **Library scan** — every 500 files: files discovered, changed count, error count
- **OCR** — every 100 images: images processed out of total, error count
- **Meaning search** — every 100 images: images indexed out of total, error count
- **Face detection** — every 100 photos: photos scanned out of total, faces found, error count

These messages appear both in the terminal (stdout) and in the rotating log file at `{data_root}/Logs/LensLedger.log`, using the same timestamped format as all other `console_log` output.

The web UI progress (HTTP-polled job status) is unchanged — this only adds terminal/log visibility.
