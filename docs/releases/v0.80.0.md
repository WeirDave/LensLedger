# LensLedger v0.80.0 — Dev tools for testing first-run flows

## Motivation

Once a library is configured, the onboarding screen, reconnection screen, and library picker are impossible to revisit without manually deleting configuration files. This makes it hard to test or iterate on those flows during development.

## What changed

A new password-protected **Dev Tools** page (`/dev-tools`) lets the developer force the home page to display any of the normally-one-time screens without changing real library state:

- **First-run setup** — shows the onboarding screen as if no library has been configured.
- **Reconnection** — shows the reconnection screen as if the library drive was disconnected.
- **Library picker** — shows the multi-library startup picker screen.

The override is held in server memory (not persisted to disk), so it resets automatically when the server restarts. A "Reset to normal" button clears the override instantly.

### Password protection

Access uses the same SHA-256 hash-based password gate as WaxFrame's dev tools. The password is verified client-side and the unlock state is persisted in `localStorage`, so it survives page reloads but not browser data clears.

### Navigation

Dev tools is accessible from the hamburger menu alongside Settings and other pages.

### Implementation details

- Added `dev_override` class attribute to `SearchHandler` — an in-memory string (`""`, `"onboarding"`, `"reconnection"`, or `"picker"`).
- `viewer_page()` checks `dev_override` before the normal asset-count logic, so overrides take priority without touching the database or library state.
- `GET /api/dev/status` returns the current override; `POST /api/dev/set` changes it.
- New files: `web/css/dev-tools.css`, `web/js/dev-tools.js`.

## Verified

- Test suite: 88 tests passed.
- Browser verification: confirmed locked state shows password form only, unlocked state shows override buttons, clicking "First-run setup" makes the home page render the onboarding screen, and resetting returns the home page to its normal view.
