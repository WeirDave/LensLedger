# LensLedger v0.43.19 — Slide-out main menu

## Motivation

The main menu was a small dropdown box that appeared below the hamburger button — a quick list of links without visual hierarchy. The sibling products (WaxFrame Professional, WD Wireless Tools) use more polished navigation patterns: full-height slide-out panels with branded headers, organized sections, and smooth animations. LensLedger's menu deserved the same treatment.

## What changed

The hamburger menu on all three pages that use it (photo library, people review, name faces) is now a full-height slide-out panel that slides in from the left edge of the screen:

- **Branded header** — the panel header shows the LensLedger logo (32×32), product name, tagline ("Your photos, understood."), and version stamp, with a close button (×) on the right.
- **Organized sections** — menu items are grouped under uppercase section labels: Navigation, Tools, and Help & Support, separated by horizontal dividers.
- **Badge counts** — Review people, Name faces, and Trash & restore show their counts in pill-shaped badges pushed to the right edge of each item.
- **Backdrop overlay** — a semi-transparent dark overlay dims the rest of the page while the menu is open.
- **Smooth animation** — the panel slides in with a cubic-bezier eased transition (0.25s), matching the WaxFrame Professional navigation panel.
- **Multiple close methods** — close via the × button, clicking the backdrop, pressing Escape, or clicking outside the panel.

The map and scan-photos pages were not changed — they use a different header structure with back links and inline quick-nav, which is the correct pattern for those single-purpose screens.

## Verified

- Test suite: 79 tests, all passing.
- Visual verification: opened the menu in the browser preview, confirmed the slide-out animation, branded header, section labels, badge counts, and dividers all render correctly in dark theme.
- Tested all close methods: close button, backdrop click, Escape key — all work correctly with both panel and backdrop dismissed together.
- Confirmed no new console errors from the menu interactions.
