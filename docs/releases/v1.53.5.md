# Face detection stops printing image decoder warnings to the console

## Why this release

- While face detection ran, the console could fill with lines such as `Invalid SOS parameters for sequential JPEG`, with no time, file name or explanation.
- The lines came from the image decoder. They described harmless oddities in how a file was saved, the photo was still read, and they looked like program errors.

## What changed

### Face detection

- JPEG and PNG photos are read with Pillow, which does not print decoder warnings. Lines such as `Invalid SOS parameters for sequential JPEG`, `Corrupt JPEG data: … extraneous bytes before marker` and `libpng warning: …` no longer appear for them.
- 16-bit greyscale PNG files are still read by OpenCV.
- Notices about unrecognised TIFF tags, damaged camera data and very large pictures are no longer printed.
- A photo that cannot be read is still listed with its error.
- Photo files are not modified, and photos are turned upright from the same camera orientation setting as before.
- Reading a JPEG takes slightly longer, about 35–40 ms for a 12-megapixel photo on the test computer.

## Verified

- Full test suite: 745 tests, all passing.
- Generated JPEG and PNG files, including all eight camera orientations, decoded to the same pixels as OpenCV produces, with nothing written to the console. A truncated JPEG, which OpenCV cannot decode by itself, was also read.
