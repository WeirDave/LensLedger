## Auto-import fires before scans, clean console output

### Startup order fix

Auto-import now fires 5 seconds after startup, and the folder watcher fires at 30 seconds. Previously both fired close together with the watcher going first, which meant scanning 50,000 unchanged files before importing any new ones. Now new photos get imported first so the scan picks them up in the same pass.

### Clean console output

The console window was showing raw diagnostic output from `scan_library()` and `ocr_assets()` — lines like `scanned: 50396`, `changed: 0`, `ocr attempted: 12`, etc. These are useful for CLI usage but cluttered the server console alongside the nicely formatted `console_log` timestamps.

Added a `quiet` parameter to both functions. The web server passes `quiet=True` so only the clean timestamped lines appear. CLI usage is unchanged.
