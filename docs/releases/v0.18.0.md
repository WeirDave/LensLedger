LensLedger now turns embedded photo locations into a useful, private world view
and brings everyday maintenance into the application.

The new Photo Map reads EXIF GPS coordinates during an incremental library scan,
groups nearby photos, and links each place back to the matching library view. It
uses a bundled world layer and does not contact an online map or tile service.
Coordinates remain in LensLedger's local catalog and are never written back to
media files.

Library Health & OCR reports database integrity, schema status, mapped-photo and
people-review counts, Review Bin items, and text-recognition progress. A verified
SQLite backup can be created without leaving the viewer. OCR can now pause after
active files finish and resume later without retrying images that were already
checked but contained no visible text.

## Included

- Local read-only Photo Map with nearby-location clustering
- Schema migrations for GPS and durable OCR completion state
- Pausable and resumable background OCR
- Library health and verified database-backup controls
- Clearer **Search scope** wording
- End-to-end safety tests for publishing, restoration, Review Bin, CSRF, path
  confinement, background work, diagnostics, mapping, and backups
