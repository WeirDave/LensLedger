## Light mode button styling fix

The enlarge and trash overlay buttons added in v0.44.0 inherited white text from the global button style, making them invisible against the light-mode photo backgrounds. They now use `var(--text)` so the text is dark in light mode and light in dark mode.

Also replaced the 🗑 emoji (which rendered as an ugly cylinder on some platforms) with a "✕ Trash" text label, matching the "⛶ Enlarge" button style for consistency.
