# LensLedger v0.43.4 — Fix insightface scikit-image deprecation

## Context

InsightFace's `face_align.estimate_norm()` calls `SimilarityTransform.estimate()`,
which scikit-image deprecated in v0.26 with a FutureWarning and will remove entirely
in v2.2. This warning appeared every time face detection ran, and once scikit-image
2.2 ships it would become a hard `AttributeError`, silently breaking face detection
for all users with no explanation.

## What changed

Added a monkey-patch in `load_insightface_runtime()` (`src/face_locations.py`) that
replaces insightface's `estimate_norm` function with a version-safe implementation:

- Uses `SimilarityTransform.from_estimate()` when available (scikit-image >= 0.26)
- Falls back to the original `SimilarityTransform.estimate()` on older versions

The patch is applied once when the insightface runtime loads, before any face
analysis runs. This means:

- No modification to site-packages needed — survives insightface upgrades
- All users get the fix automatically
- Works across all scikit-image versions (old and future)
