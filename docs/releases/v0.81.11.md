## What changed

Removed the text truncation (`overflow: hidden`, `text-overflow: ellipsis`, `white-space: nowrap`) from the lightbox file path in the faces review page. The full relative path is now always visible — there's enough room at the default viewport width (1366px) so truncation was unnecessary.

This is a follow-up to v0.81.10, which fixed the garbled path caused by `direction: rtl`. That fix switched to `direction: ltr` but left the truncation in place; this removes it entirely.

## Verified

- Full test suite: 88 tests passed.
- Visually verified in the browser: opened the faces review lightbox and confirmed the full path displays without truncation.
