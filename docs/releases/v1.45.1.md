# People index loses a button that scans already cover

## Why this release

- Since 1.45.0 a completed scan restores missing people links by itself. The **Restore from photo names** button on the people index did the same thing on request, so it is no longer needed.

## What changed

### People index

- The **Restore from photo names** button, its confirmation window and the request behind it were removed.

### Settings

- **Settings** > **People** > **Restore people from photo names after each scan** is unchanged and on by default. Turning it off stops the automatic restore, and there is no longer a button to run it by hand.

### Manual

- Both manuals describe the automatic restore under **Managing people** and no longer mention the button.

## Verified

- Full test suite: all passing. The tests for restoring people now call the restore directly instead of going through the removed button.
