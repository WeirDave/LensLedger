# LensLedger v0.59.2

## User Manual opens in a new tab

The User Manual link in the navigation menu previously navigated away from the current LensLedger page. This meant users lost their place and couldn't reference the manual while working.

The link now opens in a new browser tab (`target="_blank"`), so users can keep LensLedger open on one side of the screen and the manual on the other.
