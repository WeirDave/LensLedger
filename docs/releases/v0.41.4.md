## Motivation

The v0.41.3 info button restyle used a hardcoded accent color for the border
and an oversized 20px circle with a serif italic font. This looked functional
but didn't follow the standard pattern for a modern CSS-drawn info icon — it
should use `currentColor` to inherit the surrounding text color, be compact,
and feel like a native part of the page.

## What changed

Adopted the standard CSS-text info icon pattern across both pages:

- `border: 1px solid currentColor` — inherits `--text-secondary` naturally,
  works in both themes without hardcoding.
- `16x16px` — compact, proportional to the label text beside it.
- `inline-flex` with centering — reliable cross-browser alignment.
- `cursor: help` — the standard cursor for "more information" affordances.
- `font-family: inherit` — uses the page's system font instead of a serif.
- Hover brightens to `--text` for subtle interactive feedback.

### Files changed

- `web/css/viewer.css` — updated `.info-button` base styles.
- `web/css/scan-photos.css` — matching styles for the scan page.

## Verified

- Test suite: 79 tests passed.
- Browser verification: confirmed 16px buttons with `currentColor` border,
  transparent background, help cursor, and correct hover state.
