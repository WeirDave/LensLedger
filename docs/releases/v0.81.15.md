## What changed

The count-based progress intervals from v0.81.12/v0.81.14 were unreliable — the library scan ran for 34 seconds with 50K files and produced zero progress lines, because the modulo-based thresholds didn't align reliably with the callback frequency.

Switched all four scan phases to time-based progress logging: a line appears every 10 seconds while the scan is running. This guarantees visibility regardless of how many items are being processed or how fast they go.

Example output during a scan:

```
Photo locations: scanning C:\Dropbox\Photos
Photo locations: ~49,718 files to check
Photo locations: 14,200 / ~49,718 files checked, 3 changed
Photo locations: 32,800 / ~49,718 files checked, 12 changed
Photo locations: 48,100 / ~49,718 files checked, 56 changed
Photo locations: done — 56 changed, 69 removed, 49,666 total assets
```
