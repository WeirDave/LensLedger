# LensLedger v0.43.5 — Update third-party dependency version floors

## Context

LensLedger pins minimum versions for its third-party dependencies in three
requirements files (`requirements.txt`, `requirements-face.txt`,
`requirements-semantic.txt`). The previous floors were set when each
dependency was originally added and had drifted behind the current releases.

## What changed

Bumped every minimum-version floor to the latest available release on PyPI:

| Package | Old floor | New floor |
|---|---|---|
| Pillow | 10.0 | 12.3 |
| pillow-heif | 0.16 | 1.5 |
| onnxruntime | 1.24 | 1.28 |
| open_clip_torch | 2.32 | 3.3 |
| torch | 2.7 | 2.13 |

`insightface` was already at the latest release (1.0.1) and was left
unchanged.

## Verified

- Full test suite: 79 tests passed.
