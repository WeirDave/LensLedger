## Why this release

When the folder watcher detected new or changed photos, it only ran the library/location scan — indexing files and reading EXIF metadata. It never chained into OCR, meaning search, or face detection. This meant new photos were technically "discovered" but never fully processed. The only way to get complete coverage was to manually click "Run all scans" every time. If you left a scan running overnight, you'd come back to find that the library scan finished hours ago but OCR, meaning search, and face detection never started.

Additionally, when any scan completed there was no summary of what work remained, making it impossible to tell whether your library was fully processed or still had thousands of photos waiting.

## What changed

### Folder watcher chains all scan types

The background folder watcher now runs the full scan pipeline automatically:

1. **Library/location scan** — discovers new files, reads EXIF/GPS metadata
2. **OCR** — extracts visible text from images (signs, screenshots, receipts)
3. **Meaning search** — encodes visual content so you can search by description (only if the model is installed)
4. **Face detection** — finds faces for People identification (only if the model is installed)

Each step only runs if there are photos that need it, and each respects the existing pause/cancel controls — you can still stop any individual scan from the UI mid-chain. If a step is cancelled or fails, the chain stops and the next watcher tick picks up where it left off, since all scans are incremental.

The auto-import pipeline also benefits: after importing files it triggers the folder watcher, which now chains through all scan types instead of just the library scan.

### Scan status logging

After each scan completes, LensLedger now logs a summary of remaining work:

```
Scan status: 342 need OCR, 15 need meaning search, 89 need face detection
```

Or when everything is done:

```
Scan status: all photos fully processed
```

This appears in the in-app log and the log file, so you can always see where your library stands.

### Clearer OCR date filter

The OCR section's date filter was labeled "Only since" which looked like a status date rather than an input filter. It now reads "Skip photos before" with a tooltip explaining it filters by capture date.
