# LensLedger v0.67.0 — Wider face matching pipeline

## Motivation

With 49,000+ unidentified faces, the face suggestion pipeline was too conservative. Users who had named a dozen faces of the same person on the Name Faces page found that People Review still produced very few suggestions. Three problems compounded:

1. The suggestion threshold (0.76 cosine similarity) rejected many valid matches in the 0.65–0.76 range.
2. The "Also looks like" search when naming a face only checked the 4,000 newest faces, missing older photos of the same person.
3. Name Faces kept showing faces that already had pending suggestions in People Review, causing duplicate work.

## What changed

### Lower suggestion thresholds

`SUGGESTION_THRESHOLD` dropped from 0.76 to 0.70 and `SUGGESTION_MARGIN` from 0.04 to 0.02 in `face_learning.py`. This means the learn process generates more suggestions from existing profiles — faces that were silently dropped before will now appear in People Review for human confirmation. The auto-confirm threshold (0.90) is unchanged, so only high-confidence matches still skip review.

### Broader "Also looks like" search

When a user names a face on the Name Faces page, `_find_similar_unidentified_faces` now searches up to 50,000 faces (was 4,000) with a similarity threshold of 0.65 (was 0.76), and returns up to 50 matches (was 16). This means naming one face immediately surfaces far more of that person's photos for bulk confirmation.

### Name Faces filters out suggested faces

The Name Faces queue (`/api/faces/unidentified`) now excludes faces with `state='suggested'` in addition to `state='confirmed'`. Once learn() creates a suggestion for a face, it moves to People Review rather than lingering on Name Faces asking "Who is this?"

### Consistent unidentified face counts

All three unidentified face count queries (homepage nav, People Review queue, diagnostics) now exclude faces with pending suggestions, giving a more accurate count of faces that truly need manual attention.

## Files changed

- `src/face_learning.py` — lowered `SUGGESTION_THRESHOLD` (0.76 → 0.70) and `SUGGESTION_MARGIN` (0.04 → 0.02)
- `src/photo_search.py` — broader similar-face search (50K pool, 0.65 threshold, 50 results), Name Faces excludes suggested faces, updated count queries
- `tests/test_face_learning.py` — adjusted weak-face test angle (45° → 48°) to stay below new threshold

## Verified

- **Test suite**: 80 tests, all passing.
