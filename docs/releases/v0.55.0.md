## Context

As part of a comprehensive UX audit, two gaps remained: the About information was inconsistent across pages (some used `alert()` dialogs, the viewer had its own modal builder, and Settings/Auto-ingest had nothing at all), and the viewer's Quick Guide lacked any mention of keyboard shortcuts or mouse gestures.

## What changed

### Consistent About panel across all pages

A unified About overlay is now generated server-side in `nav_menu()` and included on every page. It displays:

- Product name, version, and tagline
- Current photo library path
- A description of what LensLedger does
- Links to other projects by the developer (WaxFrame Professional, WaxFrame Free, Subscription Wizard, WD Wireless Tools)

All seven JS files were updated to open this shared overlay instead of their previous implementations:
- `viewer.js` — replaced the `openModal`-based About builder
- `faces-review.js`, `people-review.js`, `scan-photos.js`, `map.js` — replaced `alert()` calls
- `settings.js`, `auto-ingest.js` — added About handler (previously had none)

The overlay CSS was added to all seven page stylesheets for consistent appearance.

### Keyboard and mouse shortcuts in the viewer Quick Guide

The viewer's Quick Guide panel now includes a "Keyboard & mouse shortcuts" section with a formatted table covering:

- Left/Right arrow keys for photo navigation
- Double-click to reveal the file in Explorer
- Triple-click for 3x zoom
- Click and drag to pan
- Ctrl+click for batch selection
- Shift+click for range selection
- Escape to close viewer/panel

## Verified

- **Test suite**: 79 tests passed, 0 failures (Python 3.11)
- **Browser verification**: About overlay tested on the viewer page (opens from menu, close button works, backdrop click dismisses) and the settings page (opens correctly, displays version/library/links, close button works)
