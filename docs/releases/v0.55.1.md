## Context

The "restart now" banner — which detects when a newer version of LensLedger is on disk and offers a one-click restart — was only present on the viewer (home) page. If a user was on Settings, Scan, Map, or any other page when a new version landed, they would never see the banner until they happened to navigate home.

## What changed

Added the `checkServerVersion` polling function and stale-banner CSS to all six non-viewer pages:

- **Settings** (`settings.js` / `settings.css`)
- **Auto-ingest** (`auto-ingest.js` / `auto-ingest.css`)
- **Scan photos** (`scan-photos.js` / `scan-photos.css`)
- **Photo map** (`map.js` / `map.css`)
- **Name faces** (`faces-review.js` / `faces-review.css`)
- **Review people** (`people-review.js` / `people-review.css`)

The function polls `/api/version` every 30 seconds. When the on-disk version differs from the running version, it prepends a warning banner at the top of the page with a "Restart now" button and a dismiss button. Clicking restart triggers `/api/update/restart-source`, then polls until the server comes back and reloads the page.

The map page previously had no CSRF token available in its bootstrap data; a `data-ll` attribute with the CSRF token was added to its `<body>` tag so the restart POST can authenticate.

## Verified

- **Test suite**: 79 tests passed, 0 failures (Python 3.11)
- **Browser verification**: Settings, Map, and Scan pages all load cleanly with no JS errors; version check runs and correctly shows no banner when versions match
