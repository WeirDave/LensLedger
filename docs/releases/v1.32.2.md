# Browser tab shows the version number

## Why this release

- The browser tab for the main search page read "LensLedger — Your photos, understood.", which is cut off in a narrow tab and does not say which version is running.

## What changed

### Browser tab

- The main search page's tab title is now "LensLedger v1.32.2" (the installed version). The tagline is no longer part of the tab title.
- The People Index page, which shares that page, shows "People Index — LensLedger v1.32.2".
- The tagline is unchanged in the About panel, the menu and the setup pages.

## Verified

- Full test suite: all passing.
