## Button label wrapping fix

The v0.43.18 fix for the "This photo contains [person name]" button used `text-overflow: ellipsis` to truncate long names, but that still hid the full name. Changed the approach: the button now uses `word-break: break-word` so long person names wrap to a second line and remain fully readable, rather than being cut off or truncated with an ellipsis.

## Verified

- Test suite: 79 tests, all passing.
- Browser verification: confirmed `.toggle-wrong` button uses `word-break: break-word` with no overflow — full name "Candy Jean Simmons" displays without truncation across all cards.
