# LensLedger v0.70.1 — Name Faces log shows full path

## Motivation

When naming faces, the console log printed only the filename (e.g.
`2022_11_04_20_06_59_PM_1.jpg`). With thousands of photos spread across
many folders, there was no way to tell from the log which folder a photo
lived in — making it hard to locate in the library.

## What changed

The `[Name faces] Named "..." in ...` log line now prints the photo's
`relative_path` (e.g. `2022/November/2022_11_04_20_06_59_PM_1.jpg`)
instead of the bare filename.

## Verified

- **Test suite**: 80 tests passed (Python 3.14, Windows 11).
- The test that exercises the Name Faces endpoint confirmed the log line
  still prints correctly (test photo is at the library root, so
  relative_path equals the filename — expected behavior).
