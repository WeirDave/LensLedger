LensLedger had a single dark theme with hundreds of hardcoded hex
colors spread across seven CSS files. There was no way for users
who prefer a light interface to switch, and no respect for the
operating system's color scheme preference.

## What changed

### Shared theme file (`web/css/theme.css`)

A new CSS file defines ~80 color tokens as custom properties on
`:root`. Every visual element — backgrounds, text, borders, buttons,
chips, modals, progress bars, map markers — has a named token.

The file defines three layers:
1. **`:root`** — dark palette (the default).
2. **`[data-theme="light"]`** — light palette override when
   the user explicitly chooses light mode.
3. **`@media (prefers-color-scheme: light)` guarded by
   `:root:not([data-theme="dark"])`** — follows the OS preference
   when the user hasn't made an explicit choice.

### All CSS files converted to use tokens

Every page-specific CSS file (`viewer.css`, `onboarding.css`,
`scan-photos.css`, `map.css`, `people-review.css`, `faces-review.css`,
`person-picker.css`) was rewritten to replace hardcoded hex colors
with `var(--token-name)` references. No visual change in dark mode;
the light palette is new.

### Theme toggle button

Every page now has a theme toggle button in the header:
- **Viewer page**: next to the hamburger menu button
- **Map, Scan photos, People review, Faces review**: in the
  header bar, near the version badge
- **Onboarding**: in the brand header

The button shows a sun icon in dark mode and a moon icon in light
mode. Clicking it toggles between the two.

### Theme persistence (`web/js/theme.js`)

A small script loads synchronously (not deferred) so it can apply
the saved theme before the page paints, avoiding a flash of the
wrong theme:

1. Reads `ll-theme` from `localStorage`.
2. If set to `light` or `dark`, stamps `data-theme` on `<html>`.
3. Otherwise, falls through to the `prefers-color-scheme` media
   query in CSS.
4. Listens for OS theme changes and updates the toggle icon if
   no explicit preference is saved.

### Light palette design

The light palette uses:
- White surfaces (#ffffff) and light gray backgrounds (#f0f2f5)
- Dark text (#1a1d24) with medium-gray secondary text (#5f6a7a)
- Slightly deepened accent orange (#c06a20) for contrast on white
- Soft shadows instead of dark drop-shadows
- Warm gradient preserved on onboarding/scan pages (shifted lighter)

## Verified

- Test suite: 79 tests, all passing.
- Browser testing (desktop): dark mode renders identically to
  before. Toggled to light mode — all surfaces, text, inputs,
  buttons, chips, filmstrip, sidebar, and modals use the light
  palette. Toggled back to dark — fully restored. Theme persists
  across page navigation (set light on map, navigated to viewer,
  light mode carried over).
- Verified theme.css, theme.js, and theme-toggle button present
  on viewer, scan-photos, map, people-review, and faces-review
  pages.
- No console errors from theme code.
