# LensLedger v0.61.0

## Renamed "Auto-ingest" to "Auto-import photos"

"Auto-ingest" was developer jargon. The feature imports photos from a source folder into a sorted collection, so "Auto-import photos" is what users would actually call it.

### What changed

- Nav menu item: "Auto-import photos" (was "Auto-ingest")
- Page title and heading updated
- Route changed from `/auto-ingest` to `/auto-import`
- Old `/auto-ingest` URL returns a 301 redirect to `/auto-import`
- CSS and JS files renamed from `auto-ingest.*` to `auto-import.*`
- User Manual and docs updated throughout
- Toggle label and toast messages updated

### Check interval

The auto-import pipeline previously checked for new photos every 10 minutes with no way to change it. There is now a "Check interval (minutes)" field on the page, configurable from 5 minutes to 24 hours (1440 minutes). The interval is saved with the rest of the configuration and applied to the running pipeline immediately.
