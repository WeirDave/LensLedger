## In-app User Manual

LensLedger previously had a markdown reference manual (`docs/user-manual.md`) and a brief in-app Quick guide modal, but no comprehensive in-app documentation. Users without a markdown viewer had no way to read the full manual.

This release adds a proper HTML User Manual page served at `/manual`, accessible from the navigation menu under Help & Support. The manual is a fully styled, scrollable page matching the app's theme, with a two-column table of contents and 16 collapsible sections.

### What's included

- **Table of contents** with anchor links to each section
- **16 sections** covering every feature: getting started, library management, scanning (GPS, OCR, meaning search, face detection), searching and browsing, viewing and editing metadata, people and faces, photo map, auto-ingest, publishing metadata, review bin, batch editing, database and backups, settings reference, keyboard shortcuts, supported file formats, and advanced configuration
- **Tables** for settings, model comparisons, file format support, command-line options, and data directory layout
- **Tip callouts** for important notes
- **Back to top** links in every section
- **Responsive layout** that works on narrow screens
- **Hamburger menu** with active highlighting on the manual link

### Technical details

- New `manual_page()` handler in `photo_search.py`
- New `web/css/manual.css` with manual-specific styles plus nav/about/stale-banner shared styles
- New `web/js/manual.js` for menu toggle, about overlay, and panel interactions (external script, CSP-compliant)
- Nav menu link added under Help & Support section

## Verified

- Test suite: 79 tests passed.
- Browser verification: visually confirmed the manual page renders correctly with table of contents, section cards, tables, tip callouts, and responsive layout. Confirmed hamburger menu opens and shows all navigation links with the User Manual link active.
