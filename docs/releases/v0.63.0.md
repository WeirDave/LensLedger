## Settings page overhaul — TOC, auto-import controls, smarter defaults

### Settings table of contents

The Settings page now has a sticky left-hand sidebar with links to each section. As you scroll, the current section highlights automatically. On narrow screens (under 800px) it collapses to a horizontal row of links at the top.

Sections: Photo libraries, Scan preferences, Meaning search, Display preferences, Folder watching, Auto-import photos, Database.

### Auto-import controls in Settings

Auto-import now has its own section in Settings with an enable toggle and check interval field, matching the folder watching section. A "Configure source, destination, and sorting rules" link takes you to the full auto-import page for detailed setup.

### Smarter defaults and immediate startup checks

- Folder watching now defaults to **enabled** with a **5-minute** interval (was disabled, 30 minutes).
- Both folder watching and auto-import fire their first check **immediately on startup** (10–15 seconds after launch) instead of waiting for the full interval. You open LensLedger, and it starts working right away.

### Toast visibility fix

The "Settings saved" toast notification was white text on pale beige in light mode — nearly invisible. Both light and dark themes now define explicit `--toast-text` colors so the toast is always readable.

### Full library path in nav menu

The nav menu's "Current library" footer now shows the full path (e.g. `C:\Dropbox\Photos`) instead of just the folder name (`Photos`). This matters when libraries are on different drives or in nested folders.
