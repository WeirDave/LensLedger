# LensLedger v0.43.23

## About button bootstrap data fix

The menu redesign in v0.43.19 added an About pill button to all three page menus (photo library, people review, name faces). The About click handler reads `LL.appVersion` and `LL.appTagline` from the page's bootstrap data to show version and tagline in the alert.

The main viewer page already included `appVersion` and `appTagline` in its bootstrap data, but the people-review and faces-review pages did not — their bootstrap only passed `csrf` (and `initialPersonId` for people-review). This caused the About alert on those two pages to display "undefined" for both values.

Fixed by adding `appVersion` and `appTagline` to the `bootstrap_attr` calls for both pages.

## Collapsible menu sections

Studied the WaxFrame Professional menu structure and aligned the LensLedger menu to match:

- Converted flat `<div class="menu-section-label">` headings to collapsible `<details class="menu-section">` / `<summary class="menu-section-label">` groups, matching WaxFrame's pattern exactly.
- Navigation section opens by default (`open` attribute); Tools and Help & Support sections start collapsed.
- Added a disclosure triangle (`▸` / rotated `▸`) via CSS `::before` pseudo-element with a smooth rotation transition.
- Widened the menu panel from 300px to 320px to match WaxFrame's width.
- Applied to all three pages (photo library, people review, name faces).
