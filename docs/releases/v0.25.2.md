A real coverage bug fix, honest scan messaging, a fixed map, and a new look.

## The face-detection bug that undercounted almost everyone

Live testing turned up something worse than a UI quirk: a person with 12
confirmed photos turned out to have several more visible right in the
photos folder that LensLedger had never looked at. The cause traced back
to `is_cloud_placeholder()` in `photo_index.py` — it flagged a file as
"not available locally" based on Windows attribute bits
(`RECALL_ON_DATA_ACCESS`, `UNPINNED`, `OFFLINE`) that OneDrive and Dropbox
both set on files under their management, even when those files are fully
downloaded. LensLedger was trusting that flag alone and skipping
metadata/OCR/face/meaning scanning on anything carrying it.

Verified directly against this library: a 403,920,240-byte `.tif` file
and a 119,305-byte `.jpg`, both flagged as placeholders, both had their
full byte count already allocated on disk — completely present, not
stubs. Out of 50,909 files, only 2,765 had ever been face-scanned; the
rest were being wrongly excluded.

The fix queries the file's actual on-disk allocation size against its
logical size — opened through a reparse-point-safe handle so the check
itself never triggers a download. A true placeholder has near-zero
allocation despite reporting the full logical size; a hydrated file's
allocation is always at or above it. Only files that are actually still
cloud-only now get skipped.

## Honest scan status

The Scan your photos page now states up front how many files are
downloaded and scannable versus still cloud-only, so a "complete" status
means what it says instead of quietly meaning "complete for the ~4% we
could see."

## Photo map fixes

- The location preview no longer crops photos to a fixed box — full
  photo, letterboxed if needed.
- Clicking a marker now visibly marks which one you picked (a persistent
  highlight ring), instead of leaving you guessing among a tight cluster.
- "Back to library" moved from a stray top-right button back to the same
  top-left "← Photo library" link every other page uses.

## New logo and color pass

New transparent-background app logo, and every remaining blue/purple
accent — badges, chips, map markers, background glows — replaced with
warm orange/red tones to match.
