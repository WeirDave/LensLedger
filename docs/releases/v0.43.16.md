# LensLedger v0.43.16 — Actionable scan error modal

## Motivation

When OCR or face detection encounters errors, the scan page showed a modal
listing raw error messages — PowerShell stack traces, cryptic exception names,
and internal paths. Users had no way to understand whether the errors mattered,
no easy way to share them for support, and no guidance on what to do next.

## What changed

The scan error modal now includes three improvements:

1. **Human-readable explanations** — known error patterns (AggregateException
   from Windows OCR, timeout errors, permission issues, corrupt files, memory
   errors, and face-detection failures) are matched by regex and shown as a
   plain-English hint below the raw error. The hint explains what happened and
   whether the user needs to take action.

2. **Copy all to clipboard** — a button at the bottom of the modal copies every
   error (path + message) as formatted text, ready to paste into an email or
   issue.

3. **Report on GitHub** — a link that opens a pre-filled GitHub issue at
   `WeirDave/LensLedger`, including the LensLedger version and up to 20 errors
   formatted as a markdown list.

The app version is now included in the scan page's bootstrap data so the
GitHub issue template can reference it.

## Fixed during testing

The initial regex pattern `AggregateException.*Wait` assumed the exception name
appeared before the method name in the error text, but the actual PowerShell
error output has "Exception calling Wait" first and "AggregateException" later.
Fixed the pattern to `AggregateException|Exception calling.*Wait` so it matches
either keyword independently.

## Verified

- Test suite: 79 tests passed.
- Browser verification: opened the OCR errors modal on a live library with 3
  AggregateException errors and confirmed all 3 error rows display, the "Copy
  all to clipboard" button is present, and the "Report on GitHub" link is
  present with correctly encoded URL parameters. Also verified the face
  detection errors modal (12 errors) shows the same footer controls.
- Confirmed the regex matches the actual error text from the database.
