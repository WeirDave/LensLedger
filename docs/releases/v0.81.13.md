## What changed

Face detection was attempting to process GIF files, which OpenCV 5.0.0 cannot decode due to a `bgColor >= globalColorTableSize` assertion in its GIF decoder. This produced a wall of `[ERROR:0@...]` messages on stderr for every GIF in the library — roughly 25+ lines of noise per scan, drowning out useful output.

GIF files are now excluded from face detection entirely:

- The `scan_for_faces()` query adds `AND a.extension != '.gif'` so GIFs are never loaded into OpenCV
- The `status()` function excludes GIFs from both the "eligible" and "scanned" counts so the remaining-to-scan number is accurate

Face detection on GIFs was never useful — they're typically small animated graphics, not photographs with recognizable faces.

## Verified

- Test suite: 88 tests passed (Python 3.14, Windows)
- Confirmed the OpenCV stderr errors no longer appear during face detection scans
