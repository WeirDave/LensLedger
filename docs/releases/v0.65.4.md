## Motivation

The Review People handlers were logging with the `[Name faces]` label, but they should use `[People review]` to match their source page. The Name Faces handler correctly uses `[Name faces]`.

## What changed

Changed the log label in both Review People decision handlers (single and batch) from `[Name faces]` to `[People review]`. The Name Faces handler (`name_face`) keeps `[Name faces]`.

Terminal output now looks like:

```
[Name faces] Named "Candy Jean Simmons" in selfie.jpg
[People review] Confirmed "William George Peters Jr." in dscf0010_1.jpg
[People review] Rejected "William George Peters Jr." in IMG_2044.jpg
```
