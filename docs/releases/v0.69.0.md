## Motivation

When reviewing unidentified faces on the Name Faces page, users can enlarge a photo to see its full context. Sometimes that context reveals the photo itself is unwanted — e.g. a photo taken by someone else, a duplicate, or something that doesn't belong in the library. Previously the only way to trash such a photo was to close the lightbox and click the small Trash button on the face card. Now there's a "Trash photo" button right in the lightbox header, so the action is immediate.

## What changed

- Added a "Trash photo" button to the lightbox header bar on the Name Faces page, styled with the existing danger-button treatment (dark red) to distinguish it from the other actions.
- Clicking it confirms with the user, closes the lightbox, moves the photo to the review bin, removes the face card from the grid, and shows the standard undo toast.
- Uses the same review-bin backend as the existing per-card Trash button — no new endpoints or database changes.

## Verified

- Full test suite: 80 tests passed.
- Visual verification: opened the Name Faces page in the browser, clicked Enlarge on a face card, confirmed the "Trash photo" button appears in the lightbox header with correct styling alongside "Not a person" and "Unknown person".
