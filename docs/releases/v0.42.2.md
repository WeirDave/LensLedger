## Context

When LensLedger restarts after detecting a new on-disk version (via the
stale-server banner added in v0.42.0), the updater helper opens a fresh
`cmd.exe` console running `Start LensLedger.cmd`. Python then takes several
seconds to import its dependencies and start the HTTP server. During that
time the console window was completely blank, which looked broken — there
was no indication that anything was happening.

## What changed

Added three `echo` lines in `Start LensLedger.cmd` immediately before the
`python src\photo_search.py` invocation:

```
Starting LensLedger...
```

This appears the instant the console opens, well before Python starts
loading. Once the server is ready, the normal full banner
(`LensLedger vX.Y.Z / Your photos, understood.`) still prints as before.

The message is visible both on restart and on a normal first launch — in
both cases it fills the gap while Python loads.

## Verified

- **Test suite:** 79 tests, all passing.
- **Manual review:** confirmed the echo lines appear at the right point in
  the `.cmd` script, before the Python invocation.
