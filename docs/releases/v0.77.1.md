## Retry button for catalog-busy face naming errors

When a user types a new person's name on the Name faces page and the save
fails because a scan is using the catalog, the error message appeared but
the typed name was lost. The person picker had already closed, so the only
way to try again was to reopen it, navigate to "+ New person", and re-type
the name from scratch — with no way to copy-paste it either.

Now, when a name save fails, a **Retry** button appears inline showing the
name that was attempted (e.g. `Retry "Max Benson"`). Clicking it re-submits
the same name without reopening the picker. The existing `.retry` CSS class
already in `faces-review.css` styles the button consistently with the rest
of the UI.

## Verified

- Test suite: 80 tests passed.
- Code review: the retry button reuses the `tryName` closure which clears
  any previous retry button before each attempt, preventing stacked buttons
  on repeated failures.
